# 学习路线与课程大纲

本路线面向成人中文母语学习者，目标是能理解信息、表达意图并与人完成事情。以下阶段、单元、时间建议与验收要求均为本库教学设计；参考新东方公开课程的范围见[来源与边界](../../来源与边界.md)。

## 一、先建立能力画像

先做[诊断任务](../诊断与测评/教程.md)，分别记录听、说、读、写及影响任务的基础问题。不要用“学过几年”“背过多少词”替代实际表现。读得懂而听不懂时，可能需要补声音与词义的连接；能做语法题但不会交谈时，需在有限信息下组织和回应，而不只是再看讲解。

把目标写成“在什么场景、面对谁、完成什么”。例如：“下个月能与来访同事确定会议时间，并用邮件确认”，比“提高英语”更容易选择训练内容。考试学习者另外记录考试名称、日期和官方题型要求，不能用通用课程代替考试规格。

## 二、五阶段主线

| 阶段 | 主要目标 | 基础重点 | 可保存的代表作品 | 何时继续或补弱 |
|---|---|---|---|---|
| S0 起步 | 识别常用字母、声音、数字和最基本身份信息；会请求重复 | 字母与常见音的区别；基础词重音；I am / My name is 等语块 | 听记姓名/时间，30 秒自我介绍，填写简单资料卡 | 有音频时能提取核心信息；不能时减少材料长度，补声音与词义连接 |
| S1 句子 | 用完整短句介绍日常、提出和回答简单问题 | 主谓关系、be 与一般动词、冠词/单复数、一般现在时 | 一分钟介绍、询问开放时间、5—8 句日常描述 | 换人物与时间仍能表达，听读能抓到人物、动作、时间 |
| S2 日常 | 完成预约、购物、出行等多轮沟通，描述过去和计划 | 过去、进行中和未来表达；比较；because / but / so | 改约对话、简短邮件、经历叙述 | 能发现冲突、追问确认；遗漏条件则练信息核对 |
| S3 独立表达 | 连贯叙述、解释观点、概括材料，完成一般工作交流 | 时态语境、从句、篇章连接、表达不确定性 | 2—3 分钟说明、问题解决邮件、材料摘要 | 能给理由并回应追问；用新材料检验是否只会背稿 |
| S4 复杂任务 | 比较有约束的方案、论证建议、处理异议，整合多份材料 | 语域、限定条件、转述与综合、证据和推断区分 | 方案提案、讨论记录、面向对象的说明 | 按对象需求准确传递关键信息，能修正误解并指出未知项 |

作品长度只是练习范围，不是等级标准。每阶段安排不同内容的第二次任务；按[测评规则](../诊断与测评/教程.md)决定升阶。某项不足不必把全部能力退回最低阶段。

## 三、20 单元大纲

每单元按“理解场景 → 观察范例 → 讲解语言 → 有支架练习 → 换情境运用 → 测评与回练”组织。前半段允许看提示；末尾任务撤去完整稿件，保留必要事实。一个单元可分多次学习，表中顺序不是固定日历。

| 单元 | 场景与语言重点 | 专项教程 | 当堂产出与检查 |
|---|---|---|---|
| 01 / S0 | 姓名、字母拼读、数字、基本问候 | [语音](../../基础能力/语音与发音/教程.md) | 听写五项身份信息；能请求拼写和重复 |
| 02 / S0 | 自我介绍；I am / I work / I live | [语法](../../基础能力/语法与句子/教程.md) | 用四个事实介绍自己，避免混用 be 与一般动词 |
| 03 / S0 | 看图说物；a / an、单复数、this / these | [词汇](../../基础能力/词汇与语块/教程.md) | 根据实际物品造句；词义、数量与形式一致 |
| 04 / S0 | 请重复、请慢说、确认数字 | [口语](../../听说读写/口语表达/教程.md) | 对方故意改变时间，学习者能澄清并复述 |
| 05 / S1 | 一天的安排；一般现在时、频率 | [语法](../../基础能力/语法与句子/教程.md) | 写日常并回答三个追问，第三人称形式不靠猜 |
| 06 / S1 | 时间地点；at / on / in 的具体用法 | [听力](../../听说读写/听力训练/教程.md) | 听到新安排后填写时间地点表，保留未听清项 |
| 07 / S1 | 请求与回应；can / could、礼貌表达 | [口语](../../听说读写/口语表达/教程.md) | 根据角色限制提出可执行请求，不只背一句礼貌用语 |
| 08 / S1 | 通知与短消息；疑问句、信息顺序 | [阅读](../../听说读写/阅读理解/教程.md) | 读通知找条件，再写包含对象、事项、时间的消息 |
| 09 / S2 | 一次经历；一般过去时、事件顺序 | [语法](../../基础能力/语法与句子/教程.md) | 叙述事件并说明原因；不把过去时等同于逐句加 yesterday |
| 10 / S2 | 预约与改期；未来安排、协商 | [综合任务](../../综合实践/场景任务/教程.md) | 在冲突时间中找到双方可行选项，并发确认邮件 |
| 11 / S2 | 购物与出行；数量、价格、比较 | [词汇](../../基础能力/词汇与语块/教程.md) | 比较两个方案的价格、时间和限制，解释选择 |
| 12 / S2 | 日常问题；because / so / but | [写作](../../听说读写/写作表达/教程.md) | 写清问题、原因、希望采取的行动，读者能回应 |
| 13 / S3 | 经历与当前结果；现在完成时等语境选择 | [语法](../../基础能力/语法与句子/教程.md) | 区分给定过去时间与当前相关结果，作出自然陈述 |
| 14 / S3 | 解释流程；步骤、条件、关系从句 | [口语](../../听说读写/口语表达/教程.md) | 说明一项熟悉流程，搭档据此复现并提出追问 |
| 15 / S3 | 短文摘要；主旨、细节与推断 | [阅读](../../听说读写/阅读理解/教程.md) | 三句话概括材料，标出原文没有支持的说法 |
| 16 / S3 | 一般工作交流；状态、问题、下一步 | [写作](../../听说读写/写作表达/教程.md) | 汇报进展、说明阻碍、提出明确请求与时间 |
| 17 / S4 | 方案评估；比较、让步、限定 | [综合任务](../../综合实践/场景任务/教程.md) | 对照两份材料提出建议，保留成本/交付条件 |
| 18 / S4 | 讨论与异议；澄清、转述、礼貌反驳 | [口语](../../听说读写/口语表达/教程.md) | 准确复述对方意见再回应，明确仍未解决的问题 |
| 19 / S4 | 多材料整合；来源、观点和证据 | [阅读](../../听说读写/阅读理解/教程.md) | 综合两份材料，保留冲突而不擅自补事实 |
| 20 / S4 | 最终提案；语域、结构、行动方案 | [写作](../../听说读写/写作表达/教程.md) | 完成口头说明与书面提案，接受追问后修改 |

这张表给出课程顺序和练习目标；具体语言讲解与带答案例题位于各专项，综合任务把它们连接起来。反复练习应替换人物、数字、限制、材料和读者，不能靠同一篇稿件反复达标。

## 四、一节课怎样学习

以下是 60 分钟自学/辅导课的可调整模板，不是新东方课时标准：

| 环节 | 示例时长 | 动作与产物 |
|---|---|---|
| 复现旧内容 | 5 分钟 | 合上资料，完成上次的两道题或一段表达 |
| 输入材料 | 10 分钟 | 先判断目的和主旨，再标记不懂处；听力先不看稿 |
| 讲解与示范 | 10 分钟 | 只处理妨碍当前任务的 1—2 个知识点 |
| 有支架练习 | 10 分钟 | 根据关键词、句子框架或信息表完成任务 |
| 独立迁移 | 15 分钟 | 改变条件，不照抄范例，产出录音或文字 |
| 反馈与复练安排 | 10 分钟 | 对照事实和评价标准，修正两项高影响错误，安排新材料复测 |

学习时间不足可拆成两次，但保留独立产出和反馈。查词和使用 AI 辅助时记录哪些部分得到了帮助；用辅助后的作品学习，用不依赖完整代写的作品判断独立能力。

## 五、如何借用《新概念英语》等综合教材

如果已有合法教材与音频，可把一本综合教材作为材料主线：选择能在支持下理解、又有少量新内容的一课；先听读获取意思，再拆词汇语法，最后换人物和情境重述或写作。用本库专项教程解决卡点，用综合任务检查能否迁移。

不要把“读完某册”作为能力结论；教材完成度和真实运用能力分别记录。新东方上海页面提供按册组织、讲解配合练习和测评的课程实例，但本库没有核实册数与国际能力等级的等值关系。零基础者也无需先掌握全部音标或背完一本词汇书才开始有支架的表达。

## 六、完成主线后的目标分流

| 方向 | 保留的通用基础 | 另外增加的训练与验收 |
|---|---|---|
| 日常交流 | 听懂关键条件，确认和修复误解 | 陌生场景、不同说话者、多轮信息差任务；对方能否完成事情 |
| 职场使用 | 清楚表达事实、问题、理由和行动 | 本人行业词汇、真实会议和邮件体裁；事实准确、对象合适、行动明确 |
| 校内与国内考试 | 词汇语法、阅读听力、写作组织 | 按当前官方考试说明核对题型与范围，增加限时模拟及逐题错因分析；不默认所有考试考查四项能力 |
| 留学考试与学习 | 独立听读、概括材料、解释观点 | 指定考试的官方样题与评分规则，及笔记、讨论、引用等学术任务；考试分数和学习任务分开评价 |

本页不列未经核实的考试题型、有效期或报名信息。确定考试后，另行建立该考试专题，记录当期官方来源。

## 七、执行与回顾

采用[12 周计划](12周学习计划.md)做第一轮。在每周末回答：本周能独立完成什么？证据在哪里？未完成是声音、词义、句法、组织还是事实遗漏？下周换什么材料验证？按结果调整内容，不以连续打卡天数代替能力。
