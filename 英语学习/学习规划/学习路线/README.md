# 学习路线

先按真实任务诊断起点，再沿 S0 起步、S1 句子、S2 日常、S3 独立表达、S4 复杂任务递进，用语音词汇语法支撑听说读写。适合成人重学、需要把零散知识组织成持续训练的人。

这五阶段和 20 单元大纲是本库教学设计，不是新东方官方分级或 CEFR 认证；不同专项可以从不同阶段开始。少儿启蒙、特定考试冲刺和专业翻译需要另外设计。
