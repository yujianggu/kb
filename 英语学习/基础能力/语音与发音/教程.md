# 语音与发音教程

## 学什么，以及先练什么

发音训练要解决两个相连的问题：能否从连续声音中识别词，能否让别人听出你要表达的意思。它不等于背完音标，也不等于模仿某一种口音。先处理会改变词义、语法信息或重点的问题，再处理不妨碍理解的细微差异。

本库阶段是教学安排：S0 起步建立声音与拼写的联系；S1 句子练词重音、词尾和短句；S2 日常练意群与常见弱读；S3 独立表达根据语境突出重点；S4 复杂任务在较长表达中保持清楚，并理解更多说话者的发音。阶段可以重叠，不规定完成天数。

先录一段约三十秒的自我介绍，再读五个已认识的词。请同伴不看原稿写下听到的关键词；标记没听出的地方，并用词典音频复核。若只有自己，保留录音，隔天听并与范音比较。这只能发现线索，不能替代外部听者反馈。不要仅因识别软件转写成功就判定全部正确。

## 把单词拆成可核查的信息

查词时同时看释义、音标、音节和重音，再听发音。前期可选同一词典的一种英式或美式示范保持参照一致；逐渐接触其他清晰口音。音标是记录工具，不能仅看符号猜声音。词典中的 /ˈ/ 通常标在主重音音节之前；具体符号约定以该词典说明为准。

例如 photograph 和 photography 的重音位置不同。可用 PHOtograph、phoTOgraphy 提醒自己，大小写只是本页教学标记。按音节慢读，恢复词的整体节奏，然后放进短句。不要把所有音节都读得一样重，也不要只记“第几个字母重读”。

对于 ship /ʃɪp/ 与 sheep /ʃiːp/ 这类对比，听时注意元音音质和时长的组合，不能理解为把同一个声音单纯拖长。实际时长还受语境影响。练 /θ/ 时可借助镜子观察舌尖靠近上下齿的位置并让气流通过，但应听范音检查，不能靠口型文字确认已经掌握。

词尾也承载信息：book 与 books、work 与 worked 可能涉及数量或时间。不要为了“清楚”给每个辅音后都加一个额外元音。是否存在这类问题，要看个人录音和听者反馈，不能预设每位中文母语学习者都有。

字母名、拼写和语音需要分开看。同一个字母可能对应不同声音，同一个声音也可能有不同拼写；拼读规则可以帮助预测，但遇到不确定的词仍要查音频。读缩写里的字母名，不等于读出了单词中的声音。初学者可以把“我猜它这样读”和“我已经听词典核对”分成两种记录，避免把熟悉感当成正确性。

练词尾时，也要注意书写相同不代表声音完全相同。比较 worked、played、wanted 的词典读音，最后的 -ed 并不都增加一个音节。先听出每个词整体有几个音节，再看词典转写并跟读；尚不熟悉清浊音术语时，可以先建立可靠范例，随后补规则。不要仅凭字母数量判断音节数。

## 从词重音走向句重音

词重音帮助听者识别单词；句重音帮助听者识别当前最值得注意的信息。句子“I wanted the BLUE one.”可用于纠正颜色；“I wanted TWO.”可用于纠正数量。突出重点可结合音高、时长和响度变化，不是单纯大喊。

把句子按意义分组，如“After the meeting / please send me the notes.”。斜线表示本练习建议的意群边界，不要求每次都停顿。先保证一组内部连贯，再把组之间接起来；不能机械地每三个词停一次。

连续语流中有些非重读词或音节会弱化，例如 to、a 在某些位置的读法。先在真实短音频中发现，再跟读；弱读不是随意吞掉词尾。初学时清楚而稍慢的完整表达完全可用。连读、弱读、节奏服务于理解，不是越快越好。

## 一轮十五分钟的训练

1. 选十至二十秒、有逐字文本的可靠音频，确认词义；每轮只挑一个目标，例如词重音。可以使用词典发音或有文本的教学录音，不使用自己猜读的声音作标准。
2. 不看文本听一遍，记下听到的内容；再看文本定位漏听。若完全听不出，换更短、更熟悉的片段。
3. 对照音频标重音和意群。逐句暂停跟读，再录一遍完整版本。跟读之前要知道句意。
4. 原音、录音交替听，请同伴复述两个关键事实。只修复一个最影响理解的问题，再录一次。
5. 换一个人名、时间或地点，不看原稿说新句。若只能同步模仿而不能独立说，继续这一环节。

十五分钟只是便于执行的教学建议，可按注意力调整。嘈杂环境、设备和听者熟悉程度会影响结果；记录这些条件，比较自己的前后变化。

## 练习与答案

**练习一：文字分析。** 下列词的重音应如何提示？a photograph；a record；to record a message。然后按“对方误以为明天开会，实际是周四”的语境，选择重读词：“The meeting is on Thursday.”。这项任务检查标记与语境理解，不是听辨测试。

**参考答案：** PHOtograph；REcord（名词）；reCORD（动词）。最后一句主要突出 THURSDAY。其他词仍需可听见；实际发音以所选词典音频为参照。

**练习二：真实听辨。** 请协作者先从同一词典准备 ship、sheep 两个可播放的词音频。学习者只看到 A＝ship、B＝sheep；协作者按下面执行卡播放，学习者不能看到顺序。每项正常播放一次，先作答，再允许重听核验。没有音频或协作者时，可先做听音后录音比较，不把看词猜答案记作听辨成绩。

**执行卡及答案，仅协作者先看：** sheep、ship、ship、sheep、ship、sheep；答案 B、A、A、B、A、B。第一轮后换一个顺序，避免靠记忆。六题很少，只是定位线索；下一轮要换词组或说话者，不能据此宣称全面掌握。

**练习三：信息重点。** 用同一句“I sent the file to Mia.”分别回答“Who received it?”和“Did you print the file?”，录两遍。

**参考答案：** 第一遍突出 MIA；第二遍可突出 SENT，用来纠正“打印”的假设。也可以说“I sent it. I didn't print it.”。答案取决于语境，不能把整句永久标成固定重音。

## 自评与下一步

本库建议每周保留一段相同任务录音和一段新任务录音。检查：听者是否一次听清关键词；是否需要重复；自己能否指出一个重音或词尾问题；换词后是否仍清楚。可把“三个关键信息中至少两个被准确复述”设作这一轮目标，这是练习门槛，不是等级认证。

若单词清楚但整句难懂，缩短句子并练意群；若看词会读但听不出，增加不看文本的短片段听辨；若听得出但说不稳，增加录音与延迟复述。每次只调整一个因素，再检验是否帮助真实理解。
