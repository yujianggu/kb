# 语音与发音

把声音、词形和意义联系起来，让听者能理解你说的词和重点。训练覆盖音素辨认、词尾、词重音、句重音与意群；目标是可懂度和沟通效率，不要求消除个人口音。

适用于初学、系统重学，以及“认识词却听不出、说出后常被追问”的学习者。具体问题因人而异，不能仅凭母语背景下诊断。文字材料不能代替真实音频，自动语音识别结果也不能单独证明发音正确。
