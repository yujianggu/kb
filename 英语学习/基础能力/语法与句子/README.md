# 语法与句子

用语法表达“谁做什么、处于什么状态、何时发生、信息怎样关联”。学习从完整句的主语和谓语开始，再处理时态、疑问否定、冠词与可数性、从句及句间关系。

适用于会一些单词但难以组成句子、规则题会做却难以表达，以及希望建立修改流程的学习者。教程提供基础骨架与任务练习，不覆盖全部语法现象；规则必须结合语境，不能靠中文时态词机械对应。口语片段与正式书面句的要求也可能不同。

- [案例](案例.md)：进度汇报和信息询问，均为原创教学示例。
