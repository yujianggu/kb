# 词汇与语块

把“认得中文意思”扩展为“能在合适场景中听懂、选对并用出”。一个学习单位可以是单词，也可以是 take a break、Could you help me with ...? 这样的搭配或句框。

适用于背过词却难以理解句子、表达时逐字翻译，以及需要建立长期复习系统的学习者。教程强调词义、词性、搭配、发音和主动回忆；词根与联想只作辅助，不能推断所有词义或替代语境。复习安排和自评阈值均为本库教学建议。

- [案例](案例.md)：预约和工作总结场景，均为原创教学示例。
- [来源与边界](../../来源与边界.md)：资料来源及适用限制。
