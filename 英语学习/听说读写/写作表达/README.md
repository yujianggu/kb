# 写作表达

围绕具体读者与目的，练习从事实清单、短句到连贯邮件和建议文本的写作。教程提供起草、内容修订、语言修订与迁移流程；案例展示原稿、改稿、逐项理由及练习答案。

优先检查信息是否真实、请求是否明确和语气是否适合关系，不以复杂词汇数量判断质量。示范均为原创教学示例，非真实学员或新东方教材。S0—S4 与自定评分仅用于练习，不代表 CEFR、考试或新东方官方分级；重要专业文书仍需对应领域审核。

- [案例](案例.md)：改约邮件和工作安排建议的完整修改。
- [来源与边界](../../来源与边界.md)：来源与适用限制。
