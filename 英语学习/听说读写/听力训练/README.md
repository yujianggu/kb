# 听力训练

把“听到声音、识别词块、抓住信息、核对行动”分开训练，适合成人重新建立日常英语听力。提供先听后看、定位误听原因和隔日复测的流程，以及预约与通知两个原创案例。

本库暂无配套本地音频。案例须由搭档朗读或可靠 TTS 生成音频，并在初听时隐藏脚本；只读文字不能算完成听力训练或听力测评。自定阶段与分数仅用于安排练习，不代表 CEFR、考试或新东方官方等级。部分学习者的困难来自书面词汇与声音联系不足，不能据此概括所有中国学习者。
