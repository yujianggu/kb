# 英语学习

面向中文母语学习者，把英语学习组织成“诊断 → 分阶段学习 → 专项训练 → 场景运用 → 测评调整”的完整流程。当前主线按成人重学通用英语设计，覆盖起步到较复杂的日常、职场任务；应试和留学使用共同基础，再按目标分流。

本库参考新东方部分公开课程的组织方式，教程、练习和学习案例均为本库原创教学设计，不是新东方官方课程或《新概念英语》配套讲义。参考范围与核查日期见[来源与边界](来源与边界.md)。

## 从这里开始

1. 阅读[学习路线摘要](学习规划/学习路线/README.md)，了解五个阶段及适用范围。
2. 完成[入门诊断](学习规划/诊断与测评/教程.md)，分别记录听、说、读、写的起点。
3. 按[20 单元大纲](学习规划/学习路线/路线与大纲.md)选择起始单元，配合专项教程练习。
4. 使用[12 周学习计划](学习规划/学习路线/12周学习计划.md)安排一轮训练，每周保存录音、文字作品和错因记录。
5. 完成[综合任务](综合实践/场景任务/教程.md)，再用[测评与调整案例](学习规划/诊断与测评/案例.md)决定补弱或升阶。

## 使用边界

- S0—S4 是本库的教学阶段，不是 CEFR 认证，不与考试分数、词汇量或教材册数机械换算。
- 教程覆盖学习方法、代表性知识点和可执行练习；20 单元按任务组织，持续练习时需增加同类新材料。完成阅读不等于掌握，升阶依据作品和迁移表现。
- 12 周是一轮可调整的学习安排，不承诺零基础达到某一等级。读写较强者可以保留原有优势，只补听说薄弱项。
- 当前仓库提供原创文字材料与听力脚本，未附本地音频。听力任务须配真人朗读或可靠音频；默读脚本不算听力测评。可使用来源页中的公开音频资源。
- 少儿启蒙需要年龄适配；校内应试、考试政策、专业翻译与高级学术写作不由本主线完整覆盖。
