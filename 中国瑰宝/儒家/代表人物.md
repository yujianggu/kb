| 人物 | 时代与简要介绍 | 阅读关注与来源 |
|---|---|---|
| 孔子 | 传统年代为公元前551—前479年，春秋时期鲁地的教育者与思想人物。其言论经后世传述和编纂形成多种文本传统 | 看具体对话如何讨论德行与礼；区分历史人物与后世圣人形象。[SEP](https://plato.stanford.edu/entries/confucius/) |
| 孟子 | 战国思想家，继承并发展孔子传统，强调人的道德潜能、仁政与民生条件 | 性善如何与教育、环境和主动努力关联？[SEP](https://plato.stanford.edu/entries/mencius/) |
| 荀子 | 公元前3世纪的重要儒家思想家，重视学习、礼义、人为努力与社会秩序，也讨论语言与名实 | 与孟子的分歧不只是乐观和悲观；研究其“性”“伪”的用法。[SEP](https://plato.stanford.edu/entries/xunzi/) |
| 董仲舒 | 西汉经学人物，以治《春秋》著称，参与关于教化、政治及天人关系的论述 | 《汉书》保留其对策；政治制度的形成不宜全归于一人。相关传记是古代史家叙述，应与现代研究互读。[《汉书》](https://ctext.org/han-shu/dong-zhong-shu-zhuan/zhs) |
| 程颢 | 1032—1085年，北宋思想家，世称明道先生。与弟程颐共同推动道学，重视仁及人与万物的贯通 | 二程共享一些问题，但不能把所有记录无差别归给兄弟二人。[IEP](https://iep.utm.edu/chenghao/) |
| 程颐 | 1033—1107年，北宋思想家，世称伊川先生。强调理、人性与道德修养，重视敬与求知，对朱熹影响显著 | 看修养工夫如何联系其关于理的理解。[IEP](https://iep.utm.edu/chengyi/) |
| 朱熹 | 1130—1200年，南宋思想家、教育者与经典注释家。综合前人理学，推动四书的教育地位 | 不仅看理气概念，也看读书、格物和处理具体伦理情境的方法。[SEP](https://plato.stanford.edu/entries/zhu-xi/) |
| 王阳明 | 1472—1529年，名守仁，明代思想家，也有政治与军事经历。以知行合一、致良知等论说著称 | 其对朱熹的批评属于儒学内部争论，不宜简化为“相信直觉即可”。[SEP](https://plato.stanford.edu/entries/wang-yangming/) |
| 梁漱溟 | 1893—1988年，现代哲学家，曾在北京大学讲授印度哲学与儒家哲学，参与文化论争并投身乡村建设 | 可由《东西文化及其哲学》《乡村建设理论》理解传统伦理回应现代社会问题的一种尝试。[北大校史馆](https://www.xsg.pku.edu.cn/heros/scholar/detail/762.html) |

## 怎样使用人物资料

先确定问题，再比较答案。例如讨论“学习如何改变人”，可以对读孟子的扩充、荀子的积学、朱熹的格物与王阳明的知行。不要把人物简介写成成功学履历，也不要因某人政治地位高便把其全部主张视为正确。

后续可继续收录周敦颐、张载、陆九渊、王夫之、戴震及现代新儒家人物；本次仅列线索，未为这些人物建立完整资料卡。
