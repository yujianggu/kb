## 为什么不能只背一组起止年

| 问题 | 本文的处理 |
|---|---|
| “五千年”从哪里开始？ | 讨论文明发生与发展。良渚等考古材料与上古传说是不同证据，不拿传说中某个出生年作为全国统一纪元。 |
| 夏商周年代是否和清代日期一样确定？ | 不是。夏约前2070、商约前1600等为常用推定；前1046也属于克商年代方案。前841通常视为传世历史连续可靠纪年的起点，并非此前没有历史。 |
| 春秋战国为什么有不同分界？ | 本文用前770—前476、前475—前221；前453三家分晋进程、前403周王册立三晋等也可作为不同叙述的节点。东周王室前256结束，战国并未随之结束。 |
| 汉到底从前206还是前202开始？ | 前206刘邦为汉王，前202称帝；主表采取前206的常用纪年口径并注明。西汉终年8／9与王莽代汉发生在传统历年末、公历换年后的纪年方式有关。 |
| 魏晋禅代是265还是266？ | 常用传统年表记泰始元年为265，建国时点换算公历又见266。本文主表沿用265，并在魏、晋两行同时注明，不能把两个口径机械拼成一年空档。 |
| 三国是不是220年三国同时建立？ | 不是。魏220、蜀汉221；吴按黄武建元用222，孙权229称帝。晋代魏后，吴仍至280才亡。 |
| 五代十国是不是960结束？ | 五代结束于960；十国中北汉延至979，北宋与十国末期重叠。 |
| 辽亡是否意味着全部契丹政权终结？ | 辽1125亡，西辽另有延续；1124与1132是西迁建政与称帝的不同起算点。 |
| 南宋1276还是1279结束？ | 1276临安失守；以流亡朝廷最终败亡为界，本文取1279崖山。 |
| 元从1206、1271还是1279开始？ | 1206蒙古汗国；1271定号大元；1279灭南宋。主表元用1271，1368为大都失守与元廷北迁，不是所有蒙古政权消失。 |
| 清从1616、1636还是1644开始？ | 分别是后金建立、改国号大清、入关。清主表取1636—1912；1911辛亥革命与1912清帝退位分开。 |
| “民国1912—1949”是什么意思？ | 本文限定为中国大陆通史分期。1949中华民国政府迁台，不能把该年说成其政权在所有地区一概终结。 |

## 使用数据时的边界

- “前”表示公元前；历史纪年没有公元0年。结构化数据负数只用于表示公元前年份和排序，不是天文学年号。
- 不提供“每朝精确存在多少年”的排名。首尾是否计入、传统历法转换、并立和流亡延续都会影响结果。
- 都城只列主要政治中心，不是完整迁都表；多京制、陪都与皇帝实际驻地不同。
- 分期、王朝、政权和考古文化以 `kind` 区分。春秋、战国、十六国、五代、十国都不是一个独立王朝。
- 本表未穷尽古代各地所有政权，如吐蕃、渤海、南诏、大理及各地短期政权；研究区域史时应另立专题，不能从“未列入”推导其不重要。
- 文字表与数据采用同一组条目。交互时间轴为这些数据的展示快照，后续更新资料时需同步刷新。
