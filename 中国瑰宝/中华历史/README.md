## 八段主线

| 阶段 | 大致时间 | 抓住的问题 |
|---|---|---|
| 文明起源 | 新石器时代，约前3300—前2300年的良渚为重要实例 | 农业聚落如何形成城市、分工与早期国家？ |
| 夏商周与春秋战国 | 约前2070—前221 | 早期王朝、分封礼制、诸侯竞争与百家争鸣 |
| 秦汉 | 前221—220 | 皇帝与官僚治理、郡县与郡国、统一秩序和对外交通 |
| 魏晋南北朝 | 220—589 | 政权分立、人口迁移、族群交往、江南开发与佛教传播 |
| 隋唐五代 | 581—960，十国末期延至979 | 再统一、选官与行政制度、城市文化及唐末后的分立 |
| 宋辽夏金与蒙古／元 | 916—1368，蒙古汗国始于1206、元定号1271 | 多政权并立、商业与技术、理学、欧亚交流 |
| 明清 | 1368—1912 | 君主与官僚体制、社会经济变动、全球联系与近代危机 |
| 近现代转型 | 通常从1840讲起，延续至今 | 近代国家建设、革命与战争、社会变迁和现代化 |

各行有重叠：这是不同研究问题形成的分期，不是互斥区间。“明清”与“近代”尤其不能作为同一层级相加。宏观分期可参照[中国国家博物馆《古代中国》](https://www.chnmuseum.cn/portals/0/web/zt/gudai/default.html)；近代起点采用中国大陆通史常用的1840年口径，其他研究可按问题调整。

## 三条必须同时看的线

1. **政权线**：谁在何时治理哪些地区？区分建国、统一、迁都、分裂和灭亡。
2. **社会文化线**：人口、生产、交通、思想、文字和知识如何变化？这些变化通常不会在改朝换代时立即中断。
3. **证据线**：依据是考古、同时代文字、后世史书还是传统传说？不同类型证据不应使用相同的确定语气。

“上下五千年”是文明史概括。良渚遗址约前3300—前2300年，提供早期区域国家与城市文明的考古证据；这不等于五千年来每一年都有完整文字记录，也不意味着今天的国家疆界可以直接投射到古代。[联合国教科文组织：良渚古城遗址](https://whc.unesco.org/en/list/1592)

## 快速记忆与复习

**自编记忆句**：夏商周，秦两汉；三国晋，南北朝；隋唐五代，宋辽夏金；元明清，走向共和。

这句话用于记顺序，省略了新、更始、十六国、武周、西辽等，也没有表现宋辽夏金同时存在的关系。熟悉后必须回到[朝代时间表](朝代时间表.md)补全。

建议分三遍学习：

1. **顺时间**：先记前221、220、589、960、1271、1368、1912、1949等转折点，知道每个年份对应什么，而不只背数字。
2. **找同代**：把孔子与春秋、诸葛亮与蜀汉、李白与唐、苏轼与北宋、李清照与两宋之际、李时珍与明联系起来。
3. **作比较**：每次选一个问题，如“隋和唐如何选官”“北宋与南宋面对的主要政权有何变化”，联读朝代表、人物表和事件表。

## 收录范围

本版覆盖文明起源、主要朝代与重要并立政权，近现代只列骨干节点；不是全部帝王世系、全部地方政权、人物传记或逐年编年史。人物是代表性选择，不是功绩排名，也不意味着个人能独自解释一个时代。传说人物明确标识；文学作品和演义情节不能直接充当史实。
