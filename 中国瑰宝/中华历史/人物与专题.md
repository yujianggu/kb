# 人物与专题：从纵向时间到横向比较

配合[通史总览](README.md)、[朝代时间表](朝代时间表.md)和[来源与口径](来源与口径.md)使用。下表按**主要活动时代**归类，不以出生或逝世年份排序；同一人物可同时属于多种领域，这里只标最便于检索的一类。入选是学习线索，**不是人物排名**，也不能代表某一时期只有这些人发挥作用。政权并不限于汉族建立的王朝。古代著作的作者、成书与流传有时不是同一回事，表中的作品归属按通常的教学口径表述，不据此排除后人编订。

## 代表人物索引

### 商、周与春秋战国

| 时期 | 主要活动时代 | 类别 | 姓名 | 主要事迹／作品 |
|---|---|---|---|---|
| 商 | 晚商 | 军事 | 妇好 | 商王武丁配偶；甲骨文记录其参与军事、祭祀，殷墟有其墓。 |
| 西周 | 西周初 | 政治 | 周公旦 | 辅佐周初政治；后世礼乐叙述常以他为关键人物，具体制度归属宜分辨文献传统与考古证据。 |
| 春秋 | 春秋晚期 | 思想 | 孔子 | 倡导仁、礼与教育；言行经弟子及后学传为《论语》。 |
| 春秋战国 | 约春秋晚期至战国早期 | 思想 | 老子（传统归属） | 《道德经》传统上归于老子；人物生平与文本形成过程有争议，不能视为单一作者的确定传记。 |
| 战国 | 战国早期 | 思想 | 墨子 | 墨家代表，提出兼爱、非攻等主张；《墨子》由学派长期传承。 |
| 战国 | 战国中期 | 思想 | 孟子 | 发挥儒家仁政、人性论；言论见《孟子》。 |
| 战国 | 战国中晚期 | 思想 | 庄子 | 道家代表；《庄子》内外杂篇形成层次不同。 |
| 战国 | 秦孝公时期 | 政治 | 商鞅 | 在秦推行变法，涉及县制、军功爵等制度。 |
| 战国 | 战国晚期 | 思想 | 荀子 | 重视礼法与后天学习；《荀子》保存其学说。 |
| 战国 | 战国晚期 | 思想 | 韩非 | 法家思想集大成者之一，著有《韩非子》相关篇章。 |
| 战国 | 楚怀王时期 | 文学艺术 | 屈原 | 楚辞传统的核心人物；《离骚》等作品的具体归属仍应结合文本研究。 |
| 战国 | 战国中期 | 军事 | 孙膑 | 齐国军事人物，《孙膑兵法》竹简出土使相关文献研究有实物依据。 |

妇好的军事活动有甲骨文与殷墟墓葬两类材料可互相参照；这与后世对更早时代人物的传说叙事，证据性质不同。参见[中国国家博物馆：殷墟文物](https://en.chnmuseum.cn/Portals/0/web/exhibition/exhibitions/161120Chines-Epic/)和[联合国教科文组织：甲骨文](https://www.unesco.org/en/memory-world/chinese-oracle-bone-inscriptions)。

张骞出使首先是外交使命，不能简单写成“独自开辟丝绸之路”；见[联合国教科文组织：丝绸之路概述](https://www.unesco.org/en/silk-roads/about-silk-roads)。班昭及《女诫》的复杂历史评价可参[剑桥大学出版社：班昭研究](https://www.cambridge.org/core/books/abs/ancient-women-philosophers/reappraising-ban-zhao/CB84B98EA5ED8E2769742CF4C5C4537E)。东汉造纸的表述参[大都会艺术博物馆：公元1—500年中国](https://82nd-and-fifth.metmuseum.org/toah/ht/05/eac.html)。

## 传说与史实的边界

伏羲、女娲、神农、黄帝、尧、舜、禹是理解上古叙事的重要名字，但其传统事迹不能直接排入有确证年月的个人传记表。夏代及更早历史应结合考古材料、后出文献和不同学术解释阅读；“中华上下五千年”是文明叙述的常用说法，不表示每一年都有同等密度的同时代文字记录。上表从具有较可辨史料线索的商代人物起列；早期汉字的实物证据可从[联合国教科文组织：甲骨文](https://www.unesco.org/en/memory-world/chinese-oracle-bone-inscriptions)进一步查阅。

## 七条专题发展线

| 观察维度 | 跨时期线索 | 对照人物／材料与提问角度 |
|---|---|---|
| 政治制度 | 西周封邦与礼制叙述 → 战国变法 → 秦郡县和帝国制度 → 隋唐、宋、元、明、清各自调整中央与地方关系 → 近代共和主张。 | 周公旦、商鞅、秦始皇、隋文帝、忽必烈、朱元璋、孙中山；比较“治理范围、官员来源、中央地方关系”，避免把后代制度说成前代制度的必然结果。 |
| 思想与教育 | 先秦诸子争鸣 → 两汉儒学制度化与多种学术并存 → 佛教传播、玄学及儒释道互动 → 宋明理学／心学 → 近现代知识体系变化。 | 孔子、墨子、班昭、玄奘、王阳明、鲁迅；比较思想面对的问题、传播媒介与受众。 |
| 文字、书籍与记忆 | 甲骨、金文 → 秦代文字规范 → 简帛与纸 → 雕版与活字 → 史书、类书、小说及现代出版。 | 甲骨文、李斯、蔡伦、司马迁、毕昇、曹雪芹；区分文字形态、书写材料、复制技术和作品体裁。 |
| 科学、技术与工程 | 历法与天文、医药、农业、水利、交通不断积累；技术常由多人、跨地域和跨时代改进。 | 张衡、祖冲之、隋代运河、沈括、郭守敬、李时珍、徐光启、屠呦呦；问“记载了什么、实物留下什么、后来如何使用”。 |
| 经济与生活 | 农业和赋役是长期基础；运河、城市商业、手工业、国内与海上贸易改变各地连接方式。 | 秦汉制度、隋唐运河、宋代印刷与城市、元代贸易、明代远航；把国家政策与民间活动分开观察。 |
| 跨区域交流 | 汉代使行与草原、西域联系 → 佛教求法与东亚往来 → 唐宋元陆海网络 → 明代远航 → 清末以来的新型中外接触。 | 张骞、王昭君、玄奘、鉴真、忽必烈、郑和、林则徐；比较外交、宗教、贸易、战争各自不同的目的。 |
| 社会角色与文化表达 | 宫廷、官僚、士人、僧人、工匠、商人和家庭生活均留下历史材料，但保存机会不均。 | 妇好、班昭、武则天、李清照、毕昇、关汉卿、曹雪芹；比较谁留下文字、谁被别人书写、哪些群体较少发声。 |

大运河与丝绸之路都不是一次建成的单线工程或单人事业，分别可从[联合国教科文组织：大运河](https://whc.unesco.org/en/list/1443)和[丝绸之路概述](https://www.unesco.org/en/silk-roads/about-silk-roads)核对其跨时代、跨区域性质。

## 十道比较学习问题

以下问题适合先用[通史总览](README.md)定位朝代，再用[朝代时间表](朝代时间表.md)核对先后，最后回到本页找人物与专题；“比较”不要求寻找唯一原因。

1. 周初治理叙述、战国变法和秦代郡县各要解决什么问题？可据哪些不同类型的材料判断？
2. 孔子、墨子、韩非的主张分别面向怎样的社会秩序问题？哪些概括可能过于简单？
3. 从甲骨文到纸、雕版、活字，变化的是文字、载体还是复制方式？它们有没有长期并用？
4. 张骞、玄奘、鉴真与郑和的行动目标、路线和留下的材料有何差异？
5. 隋代与元代为什么都值得放入大运河史？两者在已有河道和新工程上的关系如何？
6. 妇好、班昭、武则天、李清照分别通过什么材料进入历史记录？这些材料各有什么局限？
7. 宋、辽、西夏、金并存时，以单一朝代为时间轴会漏掉哪些政权关系与文化互动？
8. 司马迁、司马光和曹雪芹的作品分别属于什么体裁？体裁如何影响读者对“历史”的理解？
9. 蔡伦、毕昇、李时珍、屠呦呦的事迹中，如何区分个人贡献、前人积累和团队／社会条件？
10. 如果用“政治制度、交通交流、文化表达”三条线概述秦汉、唐、元、明清，哪些同步变化能看见，哪些不能据此判定因果？
