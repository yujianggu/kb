# 道家：老庄思想与道教传统

[返回中国瑰宝](../README.md) · [思想与概念](思想与概念.md) · [代表人物](代表人物.md) · [经典导读](经典导读.md)

本目录收集围绕“道”形成的思想、人物与经典，先建立入门地图，再逐步展开。阅读时可以抓住一个问题：人怎样理解变化，并减少欲望、成见与强制行为造成的困扰？这只是本目录的阅读线索，不是对所有道家、道教传统的统一定义。

## 先分清两个观察角度

**道家思想**通常以《老子》《庄子》等为讨论中心；**道教传统**还包含组织、仪式、戒律、修持与神灵信仰。两者可以区分研究，但不能想成互不相干的两条线；后世道教不断解释和使用老庄经典。“哲学／宗教”的现代分类也不能完全覆盖古人的自我理解。[学术说明：SEP《Religious Daoism》导论](https://plato.stanford.edu/entries/daoism-religion/)

## 历史入门地图

| 阶段 | 先认识什么 | 阅读提示 |
|---|---|---|
| 先秦 | 《老子》《庄子》及其思想背景 | “道家”是后来的分类名称，不宜想象成当时已有统一组织。[SEP《Daoism》](https://plato.stanford.edu/entries/daoism/) |
| 汉代 | 黄老之学将治国、无为与修养联系起来 | 黄老不等于老庄思想的原样复制。[SEP《Religious Daoism》§2.4](https://plato.stanford.edu/entries/daoism-religion/) |
| 东汉 | 天师道等有组织宗教运动出现 | 组织史与祖师显圣叙事应分开辨认。[SEP《Religious Daoism》§3.1](https://plato.stanford.edu/entries/daoism-religion/) |
| 魏晋 | 王弼等人以注释经典发展玄学 | 玄学涉及儒道经典的重新解释，不能一律归为道教宗派。[IEP《Wang Bi》](https://iep.utm.edu/wangbi/) |
| 唐宋 | 宫观、经典与仪式在朝廷支持、宗教互动中发展 | 政治支持随时期而变，并非持续一致。[亚洲艺术博物馆：唐宋道教](https://education.asianart.org/resources/daoism-in-the-tang-and-song-dynasties/) |
| 金元以后 | 王重阳及门人发展全真传统 | 全真是后来道教的重要支脉，不是先秦道家的另一名称。[SEP《Religious Daoism》§3.7](https://plato.stanford.edu/entries/daoism-religion/) |

道教的文化影响也可以从绘画、雕塑、宫观和仪式器物理解；这些作品能帮助读者看到思想、信仰和社会生活如何交织。[大都会艺术博物馆：道教与道教艺术](https://www.metmuseum.org/fr/essays/daoism-and-daoist-art)

## 建议怎样开始

1. 先读[思想与概念](思想与概念.md)，辨清无为、自然与齐物的常见误解。
2. 对照[代表人物](代表人物.md)，分清经典所托人物、注释者和宗教祖师。
3. 按[经典导读](经典导读.md)选读章篇，记录原文、注家解释与自己的理解。

首轮学习不必追求建立一套包办一切的“道家方法论”。能说明某句话出自哪一章、回应什么问题、有哪些不同解释，就比只记名言更扎实。
