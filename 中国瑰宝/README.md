# 中国瑰宝

[全库入口](../README.md) · [分层索引](catalog.json) · [按需加载规则](../LOADING.md)

收集中华历史与思想文化中的朝代、人物、事件、经典和实践资料。以佛家、道家、儒家为首批主题，现补充中华历史的多维总览。这里的“瑰宝”是目录名称；阅读时既关注思想贡献，也保留历史背景、内部争论与适用边界。

本目录为入门资料初版，不以三家代表中国文化的全部。佛教起源于古代印度，经过传播、翻译与本土发展，成为中国文化的重要组成部分；儒、道两家也经历了长期演变，不能只以某一位人物或某一本书概括。参考：[哥伦比亚大学：三教及分类的边界](https://afe.easia.columbia.edu/cosmos/ort/teachings.htm)、[佛教在中国的发展背景](https://afe.easia.columbia.edu/cosmos/ort/buddhism.htm)。

## 怎样阅读

1. 先看各家总览，知道讨论的是哪个时代、哪种传统。
2. 选择一两个概念，结合人物和经典理解其语境。
3. 沿经典导读进入原文，核对章节、版本与译注，避免只记摘句。
4. 再看三家对照；有相近措辞时，继续检查它们是否在回答同一个问题。

每次阅读可记录四项：原文及出处、自己的解释、尚未理解的地方、与现实经验的联系。最后一项属于个人借鉴，应与原典含义分别标注。

## 收录口径

- **史实与传统叙述分开。** 人物年代、经典成书与传承故事如有争议，明确保留不确定性。
- **人物不等于全部传统。** 介绍奠基者、翻译者、注释者与后续发展者，说明各自贡献。
- **原文、解释与应用分开。** 古典引文标明出处，现代借鉴不冒称原作者的工作方法。
- **尊重不同传统。** 信仰性主张以所属传统的观点呈现；现代研究资料也注明来源。
- **来源可追溯。** 各页列出已查阅的学术资料、机构说明或古典文本入口，不以网络名言代替原典。
