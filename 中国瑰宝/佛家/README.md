# 佛家

[返回中国瑰宝](../README.md)

佛教起源于古代印度，围绕苦及其止息发展出思想、伦理、修行与共同体生活。它在传入中国后，经过译经、讲学和本土社会的长期互动，成为中国文化的重要组成部分。本目录以汉传佛教为重点，兼顾其印度来源；“中国瑰宝”的归类不意味着佛教起源于中国。[历史背景](https://academic.oup.com/reference/62340/reference-article-abstract/554135063)

## 历史脉络

| 阶段 | 入门观察重点 |
|---|---|
| 古代印度起源 | 释迦牟尼活动于公元前一千纪中叶，具体生卒存在不同推算；其教导通过共同体口传与后续文本传承 |
| 汉代以来的传入 | 佛教经印度、中亚等交流路径进入中国；翻译需要跨语言协作，传入并非某一天完成的单一事件 |
| 魏晋南北朝至隋唐 | 译经和教义研究扩大，天台、华严、禅等传统逐步发展，形成各自的经典解释与修行组织 |
| 宋以后 | 既有宗派继续演变，寺院、居士、仪式与日常生活交织；不能把宗派标签当作互不往来的封闭组织 |
| 近现代 | 太虚等推动教育和制度改革，重新讨论佛教如何回应社会生活与时代变化 |

第一行参见 [Buddha](https://plato.stanford.edu/entries/buddha/)；中国阶段参见 [History of Buddhisms in China](https://academic.oup.com/reference/62340/reference-article-abstract/554135063)、[Chan Buddhism](https://plato.stanford.edu/entries/buddhism-chan/)；近代参见[太虚研究摘要](https://buddhism.lib.ntu.edu.tw/DLMBS/search/search_detail.jsp?seq=183232)。

## 范围与读法

中国佛教还包括藏传佛教与南传上座部佛教等传统，在经典语言、传承及实践上各具特点。本目录的汉传入门材料不能替代它们各自的介绍，也不将南传上座部简单称作“小乘”。[中国佛教多样性](https://www.pewresearch.org/religion/2023/08/30/buddhism/)

“佛学”侧重教义、哲学及文献研究，“佛教”还涵盖信仰、戒律、仪式与僧俗共同体。二者可以区分研究重点，却不能完全割裂：空性、慈悲等概念本来就与解脱目标及生活实践相连。[伦理与实践背景](https://plato.stanford.edu/entries/ethics-indian-buddhism/)

阅读时分别记录：原典说了什么、后世怎样解释、自己准备如何借鉴。对轮回、净土等内容按宗教传统的主张理解；现代个人反思不等于其全部宗教意义。
