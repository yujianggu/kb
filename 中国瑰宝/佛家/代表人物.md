# 佛家：代表人物

[返回佛家](README.md) · [思想与概念](思想与概念.md) · [经典导读](经典导读.md)

佛教历史包括印度创始者、跨区域译经群体、中国思想家和近代改革者。以下按贡献选取代表，不是唯一正统名单。

| 人物与时代 | 简介及主要贡献 | 阅读入口与来源 |
|---|---|---|
| 释迦牟尼／乔达摩，约公元前一千纪中叶 | 佛教传统的创始人物，活动地域在古代北印度。其教导以苦的止息为中心。生卒年存在不同年代体系，不能把某一组年份视为学界定论 | [SEP：Buddha](https://plato.stanford.edu/entries/buddha/) |
| 鸠摩罗什，四至五世纪 | 出身龟兹文化环境的重要译经僧，在长安参与组织汉译工作。他与译场合作者使般若等大乘经典获得影响深远的汉文表达；不宜把集体翻译想象成一个人的独立书写 | [IGNCA 译经讨论](https://ignca.gov.in/divisionss/kalakosa/area-studies/east-asia-programme/across-the-himalayan-gap/23786-2/)；[《金刚经》译者题记](https://raw.githubusercontent.com/cbeta-org/xml-p5/master/T/T08/T08n0235.xml) |
| 智顗，538—597 | 隋代天台思想的重要奠基者，将经典解释与止观实践结合。理解他的意义，应同时看教义结构及其修行安排，而不只摘取“一念三千”等术语 | [SEP：Tiantai Buddhism](https://plato.stanford.edu/entries/buddhism-tiantai/) |
| 玄奘，七世纪，卒于664年 | 唐代求法僧、译经组织者，赴印度学习后返回中国，推动大量佛典翻译和唯识学研究。历史人物与《西游记》中的文学形象应分别阅读 | [IGNCA：Xuanzang](https://ignca.gov.in/divisionss/kalakosa/area-studies/east-asia-programme/across-the-himalayan-gap/23786-2/) |
| 法藏，643—712 | 唐代华严思想家，承接智俨并系统展开华严教义。其祖先来自粟特，本人生于长安，体现佛教思想发展的跨文化背景 | [SEP：Huayan Buddhism，第4节](https://plato.stanford.edu/entries/buddhism-huayan/) |
| 慧能，638—713 | 禅宗传统尊为六祖，与顿悟、自性及定慧关系等讨论密切相关。围绕他的传记和《坛经》也承担传承合法性的表达，不能将全部故事直接作为同时代实录 | [SEP：Chan Buddhism](https://plato.stanford.edu/entries/buddhism-chan/)；[《坛经》版本题记](https://raw.githubusercontent.com/cbeta-org/xml-p5/master/T/T48/T48n2008.xml) |
| 太虚，近代，卒于1947年 | 佛教改革者，倡导人生佛教，重视教育、僧团制度与社会责任。其工作回应近代社会变迁，是理解佛教现代转型的重要入口；改革主张与实际落地需要分别考察 | [台湾大学佛学数字图书馆：太虚研究摘要](https://buddhism.lib.ntu.edu.tw/DLMBS/search/search_detail.jsp?seq=183232) |

## 怎样沿人物继续读

选择一位人物，建立“时代问题—思想回答—相关文本—后续影响”四栏笔记。例如读鸠摩罗什，应关注翻译如何改变术语理解；读太虚，应关注制度和教育如何回应时代问题。人物的历史贡献、宗派尊称与信仰评价属于不同层面。

## 来源与年代说明

各行来源对应人物信息，原典题记用于核对传统署名，不用于直接证明全部传记事实。释迦牟尼、鸠摩罗什、玄奘等的生年存在不同说法，本页采用宽年代，避免无解释地选定争议日期；太虚亦有不同历法换算记年。
