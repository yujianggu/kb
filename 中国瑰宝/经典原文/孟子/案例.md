# 《孟子》案例

[本地全文](全文.md) · [分篇目录](README.md) · [来源与版本](来源.md)

以下选取三种不同的说理形式：战争比喻、君主对话中的叙事、设想情境。第四例是现代虚构教学示例。不能把这几种材料都当作已证实的历史事件。

## 1. 五十步笑百步：比较之前先确定标准

**性质与出处：原典比喻论证。**《梁惠王上》第三章（1A3），梁惠王询问自己赈济灾民却未吸引更多民众的原因。[《梁惠王上》原文](https://zh.wikisource.org/wiki/孟子/梁惠王上)

**情境与解释：**孟子顺着君主熟悉战争的背景，设问逃五十步的人能否嘲笑逃百步的人。梁惠王承认二者都属逃跑，孟子再转向农时、生活供给和教育等治理要求。论证用意是质疑君主以“比邻国稍好”充当足够标准，而非讨论一场具名战役的战果。

**讨论与边界：**可分开问：比较对象是谁？最低责任是什么？即使相对领先，是否仍未履行基本责任？但不能反过来认定所有程度差异都没有意义；在现实决策中，伤害减少多少、投入改善多少往往非常重要。比喻揭示一种问题，并不使数量比较失去价值。

## 2. 齐宣王以羊易牛：把已经发生的关切推向他人

**性质与出处：原典对话中的事件叙述。**《梁惠王上》第七章（1A7），孟子转述齐宣王见牛将被用于衅钟而不忍、命以羊替换的事，王在对话中认可此事。[《梁惠王上》原文](https://zh.wikisource.org/wiki/孟子/梁惠王上)

**情境与解释：**孟子先肯定这种不忍，再指出关切已及禽兽，百姓却未得到相应保护，从而引向推恩及保民。文本同时触及“看见牛、没有看见羊”造成的差异：已经出现的情感反应，需要继续反省其对象和范围。

**讨论与边界：**该事是《孟子》内部的叙事证据，本页未用独立史料核实其细节。它也不是一则完成了现代动物伦理论证的故事。现代类比可以提醒行动者不要只帮助最容易看见的人，但关切怎样转成资源分配，仍需可检查的规则，不能只靠一时感动。

## 3. 孺子将入井：道德起点与成熟德行有何不同

**性质与出处：原典思想实验。**《公孙丑上》第六章（2A6）。[《公孙丑上》原文](https://zh.wikisource.org/wiki/孟子/公孫丑上)

**情境与解释：**孟子请读者设想忽然看见儿童将落入井中，认为人会产生惊惧与怜悯，并排除结交其父母、博取名声等动机，借此说明不忍人之心。随后才把恻隐等称为仁义礼智之端，并提出扩充的要求。

**讨论与边界：**“有端”与“已完成修养”有区别；短暂反应如何发展成持续行动，是后续问题。这里没有实际设置危险场景或调查人群，不能冒称孟子进行了心理学实验，更不能为验证主张而让儿童置身危险。对现实中某人未立即反应，也不宜据一句古文直接断言其没有人性。

## 4. 助学名额不只给最会讲故事的人

**性质：现代教学示例，机构、人物与过程均为虚构。**借鉴第二例关于可见对象与关切范围的追问；以下安排是现代练习，不是孟子提出的助学制度。

一个社区学习小组有少量免费课程名额。组织者最先想到经常发言、曾公开谈困难的一名学生，随后意识到不发言的学生也可能有需要。小组通过私下自愿申请收集必要信息，事先公布与学习机会相关的标准，限制材料接触范围，并由两人共同核对；同等情况无法区分时采用事先说明的办法，保留申诉入口。

**练习产出：**记录分配标准、信息缺口及处理理由，不展示学生的私人困难来证明组织者有爱心。复盘检查沉默者是否有同等申请机会，未获支持者是否得到清楚解释。经典在此提供的是反省问题；具体标准的公正性和执行效果，需要参与者反馈与实际记录支持。

核验日期：2026-09-26。以上现代示例为虚构教学，不代表真实机构的制度或效果。
