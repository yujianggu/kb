# 《尚书》背景与阅读边界

《尚书》又称《书》《书经》，汇集以帝王、贵族和臣下言论为核心的古代政治文献。传世篇章所叙时代上起尧舜，下至春秋，但“叙述发生在何时”与“现存文字写定于何时”是两个问题。它不是尧舜以来逐字无缺保存的会议录，也不能用某篇托名人物的年代直接给全文断代。孔子删定《书》是传统说法，具体编集过程、各篇作者与形成时期仍须分别研究。[国家图书馆所提供《尚书》导读](https://www.nlc.cn/upload/attachments/2023-12-01/fbfab046.pdf)

常见传本按虞、夏、商、周四部分排列。传统常以典、谟、训、诰、誓、命概括文体，涉及制度典则、君臣谋议、训诫、告谕、军事誓师和任命等不同场合；这些概括有助辨认言说目的，却不是互不重叠的现代文件分类。读一篇诰命，应先辨发言者、受告对象、危机或任务，再看天命、祖先、民众和刑罚怎样进入论证，而非只抽取警句。[中国社会科学出版社《西周礼制与〈尚书〉文体研究》内容说明](https://www.csspw.com.cn/booksdetail_15923_2054803_0.jhtml)

今古文问题尤其重要。“今文”首先指汉代传授系统及当时通行文字书写的经本，不是现代白话文；“古文”涉及以先秦古文字流传的文本及相应学术传统，也不能望文生义地理解为年代必然更真、更早。伏生传本的篇数因篇章分合及《泰誓》等问题有28、29等计法。常见58篇系统包含由今文部分分合而成的33篇，以及后来受到辨伪的25篇。[李学勤谈清华竹简](https://www.tsinghua.edu.cn/info/1870/74464.htm)

后世所谓“伪古文《尚书》”，主要指东晋以来流传、托孔安国传的系统中晚出的25篇，不等于把汉代古文传统、所有《尚书》或全部早期政治思想一并判伪。宋明清学者已提出长期辨伪，清华简等早期材料又为传世篇章与佚篇的比较提供了新证据。某篇含早期引文，也不能据此把整篇成书提前；晚出文本仍可作为其形成与接受时代的思想史材料。[全国哲学社会科学工作办公室：《清华简〈尚书〉类文献综合研究》成果简介](https://www.nopss.gov.cn/n1/2024/0606/c373410-40251900.html)

《尚书》影响了后世政治语言、诏令文章、德治论述与经学史。其困难既在古奥字词，也在说话者的政治立场：宣称敬天保民，不自动证明施政实际如此；用先王寿命、灾异证明德政，也不构成现代因果验证。原典中的等级、征伐与刑罚须放回历史条件，现代应用只能明确标为启发或类比。研究具体史事，应结合篇章真伪、异文、出土文献及其他史料；本主题保存传本文字不等于认证每篇为所叙时代的原始档案。
