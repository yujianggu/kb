# 堯典

[返回目录](../README.md) · [来源与版本](../来源.md)

> 原文来源：[尚書/堯典，修订 8732107](https://zh.wikisource.org/w/index.php?oldid=8732107)。原站注记见篇末，非古文正文。

曰若稽古帝堯：曰放勛。欽明文思安安。允恭克讓，光被四表，格〔注22〕于上下。克明俊〔注1〕德：以親九族，九族既睦；平〔注2〕章百姓〔注23〕，百姓昭明；協和萬邦〔注3〕，黎民於變時雍。

乃命羲、和：欽若昊天，曆象日月星辰，敬授民時。

分命羲仲，宅〔注4〕嵎夷〔注5〕〔注24〕，曰暘谷〔注25〕。寅賓出日，平秩〔注26〕東作；日中星鳥，以殷仲春。厥民析〔注27〕，鳥獸孳尾。

申〔注28〕命羲叔，宅南交，［曰明都］〔注29〕。平秩南僞〔注30〕，敬致，日永星火，以正仲夏。厥民因，鳥獸希革。

分命和仲，宅西［土］〔注31〕，曰昧谷。寅餞納日，平秩西成；宵中星虛，以殷仲秋。厥民夷，鳥獸毛毨。

申命和叔，宅朔方，曰幽都。平在朔易；日短星昴，以正仲冬。厥民隩〔注6〕，鳥獸氄毛。

帝曰：「咨！汝義暨和，期三百有六旬有六日〔注32〕，以閏月定四時成歲。」

允釐百工，庶績咸熙。

帝曰：「疇咨若時登庸？〔注33〕」

放齊曰：「胤子朱啟明。」

帝曰：「吁！嚚訟，{可乎}〔注34〕？」

帝曰：「疇咨若予采？」

驩兜〔注35〕曰：「都！共工方鳩〔注36〕𠊩〔注7〕〔注37〕功。」

帝曰：「吁！靜言庸〔注38〕違〔注39〕，象恭滔天〔注40〕。」

帝曰：「咨！四岳〔注8〕！湯湯洪水方（旁）〔注41〕割，蕩蕩懷山襄陵，浩浩滔天。下民其咨，有能俾乂？」

僉曰：「於，鯀哉！」

帝曰：「吁！咈哉！方〔注42〕命圮族。」

岳曰：「异哉，試可乃已。」

帝曰：「往，欽哉！」

九載，績用弗〔注9〕成。

帝曰：「咨！四岳！朕在位七十載，汝能庸命，巽〔注43〕朕位？」

岳曰：「否〔注10〕德忝帝位。」

曰：「明明揚側〔注11〕陋。」

師錫〔注44〕帝曰：「有鰥〔注12〕在下，曰虞舜。」

帝曰：「俞〔注45〕，予聞。如何？」

岳曰：「瞽子，父頑，母嚚，象傲〔注46〕；克諧，以孝烝烝，乂不格姦。」

帝曰〔注47〕：「我其試哉。」

女于時，觀厥刑（型）于二女〔注48〕。釐〔注49〕降二女于嬀汭，嬪于虞。

帝曰：「欽哉！」

慎徽五典〔注50〕，五典克從；納于百揆，百揆時敘〔注13〕；賓于四門，四門穆穆；納于大麓，烈風雷雨弗迷。

帝曰：「格，汝舜。詢事考言，乃言厎可績，三載。汝陟帝位。」

舜讓于德，弗嗣〔注51〕。

正月上日，受終于文祖。在〔注52〕璇璣玉衡，以齊七政。肆〔注53〕類〔注54〕于上帝，禋于六宗，望于山川，徧于羣神。揖〔注14〕五瑞，既月乃日，覲四岳羣牧，班瑞于羣后。

歲二月，東巡守〔注15〕，至于岱宗，柴，望秩于山川，肆覲東后。協時月正日；同律、度、量、衡。修五禮、五玉、三帛、二生、一死贄，如〔注55〕五器，卒乃復。

五月，南巡守，至于南岳，如岱禮。

八月，西巡守，至于西岳，如初。

十月一月，朔巡守，至于北岳，如西禮。

歸，格于藝祖〔注56〕，用特。

五載一巡守，羣后四朝。敷奏〔注16〕以言，明試以功，車服以庸。

肇十有二州，封十有二山，濬川。

象以典刑。流宥五刑。鞭作官刑，扑作教刑，金作贖刑，眚（省）災肆赦，怙終賊〔注57〕刑。

「欽哉！欽哉！惟刑之卹〔注58〕哉！」

流共工于幽州〔注17〕，放驩兜于崇山，竄〔注59〕三苗于三危，殛鯀于羽山，四罪而天下咸服。

二十有八載，放勛乃殂落，百姓如喪考妣，三載，四海遏密八音。

月正元日，舜格于文祖。詢于四岳，辟四門，明四目，達〔注18〕四聰〔注19〕。

咨十有二牧，曰：「食〔注60〕哉！惟時柔遠能〔注61〕邇，惇德允元，而難任人，蠻夷率服〔注62〕。」

舜曰：「咨！四岳！有能奮庸，熙帝之載，使宅百揆，亮采惠〔注63〕疇？」

僉曰：「伯禹作司空。」

帝曰：「俞，咨！禹，汝平水土，惟時懋哉！」

禹拜稽首，讓于稷、契暨皋陶。

帝曰：「俞，汝往哉！」

帝曰：「弃。黎民阻〔注20〕飢。汝后〔注64〕稷，播時〔注65〕百穀。」

帝曰：「契。百姓不親，五品不遜。汝作司徒，〔注66〕敬敷五教，［五教］〔注67〕在寬。」

帝曰：「皋陶。蠻夷猾夏，寇賊奸宄。汝作士〔注68〕，五刑有服，五服三就；五流有宅，五宅三居。惟明克允。」

帝曰：「疇若予工？」

僉曰：「垂哉。」

帝曰：「俞。咨！垂，汝共工。」

垂拜稽首，讓于殳斨暨伯與〔注69〕。

帝曰：「俞，往哉。汝諧（偕）。」

帝曰：「疇若予上下草木鳥獸？」

僉曰：「益哉！〔注70〕」

帝曰：「俞。咨！益，汝作朕虞。」

益拜稽首，讓于朱、虎、熊、羆。

帝曰：「俞，往哉！汝諧（偕）。」

帝曰：「咨，四岳。有能典〔注71〕朕三禮？」

僉曰：「伯夷〔注72〕。」

帝曰：「俞，咨！伯，汝作〔注73〕秩宗。夙夜惟寅，直哉惟清。」

伯拜稽首，讓于夔、龍。

帝曰：「俞，往，欽哉！」

帝曰：「夔，命汝典樂，教胄〔注74〕子。直而溫，寬而栗，剛而無虐，簡而無傲。詩言志，歌詠言，聲依詠，律和聲。八音克諧，無相奪倫，神人以和。」

夔曰：「於！予擊石拊石，百獸率舞。」

帝曰：「龍，朕墍〔注75〕讒說殄行〔注76〕，震驚朕師。命汝作納言，夙夜出納朕命〔注77〕，惟允。」

帝曰：「咨！汝二十有二人，欽哉！惟時亮天功〔注21〕。」

三載考績，三考黜陟幽明，庶績咸熙。

分北三苗。

舜生三十徵庸，三十在位，五十載，陟方〔注78〕乃死。

20. 【原站异文注】正文作「阻」；另作「祖、徂、始」。

21. 【原站异文注】正文作「功」；另作「工」。

22. 【原站注】今文多作「假」，《實用甲骨文字典》：「𢓜」，本作「各」，指來、到來。傳世文獻多假藉「格」為「𢓜」。

23. 【原站注】王國維、楊筠如等人指出，在金文中「百姓」寫作「百生」。裘錫圭等人結合金文認為「百生」指「族人」。趙朝陽採納裘錫圭說。「姓」字古義包含子嗣、族屬之意。在《堯典》的語境中，「百姓」本義應為「百族」。後來隨著官僚體制建立，「百姓」才演變為「百官」之意。

24. 【原站注】于省吾云：「小臣𬣆簋『伯懋父以殷八師征東夷』，又云『伐海眉』，又云『䢦征自五𫜉貝。』『五𫜉』即『嵎夷』，當係東夷之一種。亦猶《楚語》之稱三苗九黎也。《禹貢》『海岱惟青州：嵎夷既略』以其背山故作『嵎』；以其面海為潟鹵之地故作𫜉。陳漢平根據下文分別言「南交」「西土」「朔方」，而疑「嵎夷」為「東嵎」之誤。

25. 【原站注】《五帝本紀》索隱載其舊本作「湯谷」

26. 【原站注】《五帝本紀》作「便程」，《尚書大傳》云「辯秩」。

27. 【原站注】析、因、夷、隩為四方神名。甲骨文《合集》14294：「東方曰析，風曰𫩻(劦)；南方曰粦(因)，風曰𡵂；西方曰𣐺(𩏏)，風曰彝；北方曰勹(伏\夗)，風曰[⿰卩殳]。」

28. 【原站注】《爾雅·釋詁》「重也」。「申命」疑即金文中常見之「申就乃命」之省語。

29. 【原站注】鄭玄注：「夏不言『曰明都』三字，摩滅也。」王肅云：「夏無『明都』，避『敬致』，然即『幽』足見『明』，闕文相避。」兹從鄭說補足。

30. 【原站注】唐石經作「訛」，錢大昕謂當作「僞」。

31. 【原站注】《史記》句中有「土」字，據之補足。

32. 【原站注】此句爲周人寫定，不全是商代語言，但也反映出商代的歲時情況。董作賓據《乙編》53（《合》20843）「五百四旬〔㞢〕七日」認為此即一年半之長度，其週年長度合於四分曆之365.25日，以整數言則為366日。至於「以閏月定四時，成歲」，武家璧說：「《左傳·文公元年》：『先王之正時也，履端於始，舉正於中，歸餘於終。』甲骨文中屢見『十三月』，就是『歸餘於終』的置閏方法。」

33. 【原站注】段玉裁云：「尋此經之語，當云『帝曰：咨。疇若時登庸』、『咨。疇若予采』，乃與『疇若予工』、『疇若予上下草木鳥獸』一例，而倒易二字者，葢史臣紀帝語恐失其真，不求明順也。《五帝本紀》云『誰可順此事』，『誰可』者則明順矣。」

34. 【原站注】皮錫瑞認為「可乎」二字像後人增入：上古文氣質樸，《尚書》少見句末助詞「乎」，且《堯典》尤不應有。

35. 【原站注】《五帝本紀》、《漢書·古今人表》、《山海經》等皆作「讙兜」，《居延漢簡（肆）》407.1亦作「讙」。

36. 【原站注】《五帝本紀》云：「共工旁聚布功，可用。」《說文》「𠊩」字下引《虞書》作「旁救𠊩功」，「逑」字下引作「旁逑孱功」。按，《國語·楚語上》「旁求四方之賢」、「旁求聖人」。清華簡（壹）《皇門》簡3：「廼方（旁）救（求）選擇元武聖夫。」「方鳩」殆應讀爲「旁求」。

37. 【原站注】北敦14681作「僎」。馬楠疑應讀爲「纂」（《周秦兩漢書經考》第53頁），白軍鵬讀爲「選」。

38. 【原站注】「庸」甲骨文用作「用」，有采用、任用、需要義。

39. 【原站注】《漢書》作「靖言庸違」，《論衡》《潛夫論》作「靖言庸回」，並可參《左傳》「靖譖庸回」。

40. 【原站注】趙朝陽認爲「象」是「爲」字的訛誤，「恭」是「洪」字的訛誤，這句話原本應作「爲洪滔天」，意思是共工治水失敗，造成了滔天洪水。這與《淮南子》中「共工振滔洪水」的記載相符，並非形容其外貌恭敬。

41. 【原站注】《經義述聞（一）》第152—153頁。

42. 【原站注】《漢書·傅喜傳》「同心背畔，放命圮族」，《薛宣朱博傳》「今晏放命圮族」。

43. 【原站注】《史記》作「踐朕位」。俞樾、裘錫圭認為「巽」不是順或讓的意思，而是假借為「纂」。「纂」意為繼承。這句話的意思是堯問四岳：「你們誰能繼承我的帝位？」

44. 【原站注】此「錫」字與《禹貢》「錫貢」、「九江納錫大龜」、「禹錫玄龜」以及《召誥》「錫周公」之「錫」並是「入獻」之意，可參鬲尊（《集成》5956）「鬲易（錫）貝于王」、麥方尊（《集成》6015）「麥易（錫）金于辟侯」。

45. 【原站注】《實用甲骨文字典》：俞，借用作答應、允許，多用為表示首肯、感慨的嘆詞。

46. 【原站注】《五帝本紀》作「弟傲」。《論衡·幸偶》云「弟象敖狂」可參。

47. 【原站注】馬鄭王本無此二字。

48. 【原站注】《論衡·正說》云：「堯聞舜賢，四嶽舉之，心知其奇，而未必知其能，故言『我其試我』。試之於職，妻以二女，觀其夫婦之法，職治脩而不廢，夫道正而不僻。」

49. 【原站注】「釐」字在金文和傳世文獻中常通用為「賚」。

50. 【原站注】自此以下，僞孔以爲《舜典》，並增「曰若稽古帝舜，曰重華，協于帝。濬哲文明，溫恭允塞。玄德升聞，乃命以位」二十八字。

51. 【原站注】「嗣」字，僞孔《傳》釋為「嗣位」之「嗣」。《史記·五帝本紀》訓作「不懌」。《索隱》云：「古文作『不嗣』，今文作『不怡』，怡即懌也。」于省吾根據毛公鼎（《集成》2841）「肆皇天亡𬙜」及其他出土文獻和傳世文獻，認為「『弗嗣』亦即不台、不怡、無辭、無辝、無𫩞、不懌、不澤、無𬙜、無斁」。

52. 【原站注】《爾雅·釋詁》「察也」。

53. 【原站注】《五帝本紀》、《封禪書》等作「遂」。《說文》：「㣈，㣇屬。从二㣇。𠭾，古文㣈。《虞書》曰：㣈類于上帝。」

54. 【原站注】同「禷」。祭祀名。祭告天神。

55. 【原站注】王引之云：「如者，與也，及也。」

56. 【原站注】《史記·五帝本紀》將此句譯述作「歸至於祖禰廟，用特牛禮」，《尚書大傳·虞夏傳》引作「歸，假于禰祖，用特」。俞樾云：「藝祖，禰祖，古今文不同。……藝當讀爲暬，暬從埶聲。古藝字止作埶。……《國語·楚語》『居寢有暬御之箴』韋注曰：『暬，近也。』暬之義爲近，禰之義亦爲近。襄十三年《左傳·正義》曰：『禰，近也。於諸廟，父最爲近也。』」大克鼎（《集成》2826）及番生簋（《集成》4326）「柔遠能邇」之「邇」作𬂴，于省吾謂其即蓺之本字，義訓爲近。藝祖，即父廟。

57. 【原站注】于省吾說讀爲「則」。
