# 《论语》案例

前三例来自原典答问与叙事；第四例为现代虚构教学情境。以下使用篇名与段首定位，避免不同版本的篇内章号差异。原典对话不等同于已获独立证实的逐字历史记录。

## 1. 同问“闻斯行诸”，为何回答相反

**性质与出处：原典师生答问。**《先进》“子路问：闻斯行诸”章。[《先进》原文](https://zh.wikisource.org/wiki/論語/先進第十一)

**情境与解释：**子路问听到之后是否马上实行，孔子提醒他父兄尚在；冉有提出同一问题，却被鼓励实行。公西华疑惑，孔子解释：冉求容易退缩，所以推动他；仲由容易过人，所以有所抑制。文本将表面的答案差异，与对发问者倾向的判断联系起来。

**可讨论之处：**把两个回答摘成互相排斥的格言，会丢掉这一章最有价值的信息。可比较相同目标之下，不同人需要怎样的支持与约束。适用边界在于：现代指导者未必准确了解学习者，宜说明判断依据并允许反馈，不能仅凭权威声称“我是为你好”。父兄的地位也须放回古代家庭关系解释。

## 2. 宰予昼寝之后，如何看待言与行

**性质与出处：原典人物叙事。**《公冶长》“宰予昼寝”章。[《公冶长》原文](https://zh.wikisource.org/wiki/論語/公冶長第五)

**情境与解释：**文本先记孔子对宰予的严厉批评，随后记下从听其言而信其行，转向听其言而观其行的说法。可注意的不是只记“朽木”这一评价，而是观察陈述与行为能否互相印证，以及评价者是否根据经历调整判断方式。

**可讨论之处：**一个承诺是否实现，需要什么可观察证据？一次失约应怎样影响、又不应怎样主宰长期评价？本章没有完整交代宰予休息的背景，不能据此宣布昼间休息本身有道德问题。现代教育也不宜把贬抑人格的词语照搬到学生或同事身上；行为反馈应具体、可解释并可改进。

## 3. 子贡问政：信任在公共秩序中的位置

**性质与出处：原典政治思想论证。**《颜渊》“子贡问政”章。[《颜渊》原文](https://zh.wikisource.org/wiki/論語/顏淵第十二)

**情境与解释：**孔子首先并列食物充足、防卫充足与民众信任。子贡两次追问不得已必须舍弃时的先后，答问遂将信置于根本位置。这是一种逐步加强条件的价值追问：除了物质与强制力量，公共秩序还依赖什么？

**可讨论之处：**不能脱离“必不得已”的设问，截取“去食”作为削减基本生活保障的政策处方。原文对信的强调，也不能被偷换成要求民众无条件相信掌权者。现代讨论应进一步追问谁须兑现承诺、如何公开证据、失信后如何问责；这些具体制度安排须另行论证。

## 4. 带两位新人主持读书会

**性质：现代教学示例，人物及过程均为虚构。**借鉴第一例的情境化指导和第二例的言行核对；以下做法不是孔子留下的主持培训法。

两位新人都希望主持下次讨论。一位准备充分却总说“等我再读完一本书”，另一位表达积极，却尚未核对所引篇章。组织者与前者约定主持十分钟并安排搭档；与后者约定先提交引文、出处和三个讨论问题，核实后再主持。两人的共同目标相同，获得的准备支持有所不同。

**练习产出：**写下各自下一步任务、完成证据与回顾时间；活动后请两人先自评，再收集参与者反馈。组织者也检查自己的最初判断是否成立，不能把“谨慎者”“冲动者”变成永久标签。如果差别安排影响公开机会，应向当事人解释依据并提供调整通道，让因人指导不变成偏爱某人的借口。

核验日期：2026-09-26。现代示例仅供讨论与试行，未声称具有普遍、已验证的效果。
