# 《诗经》来源与版本

[返回目录](README.md)

全文底本为 chinese-poetry/chinese-poetry 开放古典文献数据的固定提交，正文按原数据篇序和段落保存。

收录305篇有辞诗歌全文，并在目录末单列6篇笙诗存目；共311个条目。笙诗无传世歌词，不属于本次下载遗漏。诗歌采用来源简体字形；不收毛传、郑笺及历代注疏。

## 来源与复核

- [诗经电子文本](https://github.com/chinese-poetry/chinese-poetry/blob/b8594f81a89752241442f2ce267d6f66f96704ee/%E8%AF%97%E7%BB%8F/shijing.json)；版本：`b8594f81a89752241442f2ce267d6f66f96704ee`；获取：2026-09-26。
- [笙诗存目参考目录](https://zh.wikisource.org/wiki/詩經)；版本：`8738202`；获取：2026-09-26。

原始下载数据与篇章清单一并保存；[版本清单](版本清单.json)记录文件 SHA-256、篇名、来源和正文汉字数。哈希用于识别本地版本，不代表已经逐字校勘。

古代作品原文已进入公有领域；电子数据由 chinese-poetry/chinese-poetry 项目提供，保留项目的 [MIT 许可与版权声明](LICENSE-MIT.txt)。本次仅将 JSON 中的篇名、篇序和段落转成 Markdown，不自动修正通假字、异体字或标点，也不附加现代译文。

背景与案例为本库重新撰写的阅读辅助，其具体事实出处另列在相应页面；现代教学案例不属于古籍正文。
