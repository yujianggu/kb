# 经典案例导航

[返回经典总目](README.md)

案例页将原典叙事、比喻论证、后世解释与现代教学分开标记。原典中的事件叙述不等于已经由独立史料证实；现代场景均为虚构教学，不是历史事实。阅读案例时，可从同页顶部进入本地原文。

## [大学](大学/案例.md)

- 1. 独处作恶、见人掩饰：诚意为何不能只看表态
- 2. 爱自己的孩子，却看不到他的缺点
- 3. 引《秦誓》谈容人：有能力的人为何仍可能受阻
- 4. 社区读书会选协调员

## [中庸](中庸/案例.md)

- 1. 舜好问：听取意见之后仍须判断
- 2. 子路问强：坚守为什么不等于好斗
- 3. 哀公问政：学习最终要落实到行动
- 4. 志愿活动日期争议

## [论语](论语/案例.md)

- 1. 同问“闻斯行诸”，为何回答相反
- 2. 宰予昼寝之后，如何看待言与行
- 3. 子贡问政：信任在公共秩序中的位置
- 4. 带两位新人主持读书会

## [孟子](孟子/案例.md)

- 1. 五十步笑百步：比较之前先确定标准
- 2. 齐宣王以羊易牛：把已经发生的关切推向他人
- 3. 孺子将入井：道德起点与成熟德行有何不同
- 4. 助学名额不只给最会讲故事的人

## [诗经](诗经/案例.md)

- 一、《周南·关雎》：从反复中读出情绪变化
- 二、《卫风·氓》：把承诺、行动和叙事立场分开
- 三、《豳风·七月》：劳动日历也是资源分配图
- 四、现代教学示例：为一首诗制作“证据卡”

## [尚书](尚书/案例.md)

- 一、《盘庚上》：迁徙动员中的理由与权力
- 二、《无逸》：用前代人物建立劝诫链条
- 三、《洪范》“稽疑”：多方意见并不等于现代投票
- 四、现代教学示例：为图书馆搬迁写一份理由说明

## [礼记](礼记/案例.md)

- 一、《檀弓下》“嗟来之食”：不要删掉结尾的评论
- 二、《学记》：善教需要看见学习者的困难
- 三、《礼运》：比较“大同”与“小康”的论证功能
- 四、现代教学示例：修改一张救助领取通知

## [周易](周易/案例.md)

- 一、《乾》：爻位变化不等于一路攀升
- 二、《既济》：事情做成之后仍有新的问题
- 三、《系辞上》第八章：解释如何把意象转成伦理
- 四、现代教学示例：系统上线后的“既济”讨论

## [春秋](春秋/案例.md)

- 一、隐公元年：一句“郑伯克段于鄢”能说明多少
- 二、庄公十年：战果记录不是战术复盘
- 三、僖公十六年：保留数量和时间，暂不添加征兆
- 四、现代教学示例：为校园活动建立可追溯纪事

## [史记](史记/案例.md)

- 1. 鸿门宴：同一局面中的多方判断
- 2. 约法三章：承诺与政治处境
- 3. 文帝罢露台：成本怎样进入评价
- 4. 三代世表：让不确定性可见
- 5. 萧何推荐韩信：识人需要说清依据
- 6. 商鞅徙木：承诺兑现与政策后果
- 7. 廉颇与蔺相如：共同目标与冲突处置
- 8. 李广：评价不能只看一个结局
- 9. 货殖列传：经济活动的多种位置
- 10. 太史公自序：观察全书怎样组织知识
