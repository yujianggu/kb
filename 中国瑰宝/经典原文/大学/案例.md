# 《大学》案例

前三例是原典的思想论证及典型情境，第四例是虚构的现代教学示例。篇本与朱熹章句本顺序不同，以下以原文段首定位；引文中的古字可按所用版本核对。

## 1. 独处作恶、见人掩饰：诚意为何不能只看表态

**性质与出处：原典思想论证。**《大学》“所谓诚其意者，毋自欺也”段，继而描写小人独处时作不善之事，遇见君子才遮掩过错、显露自己的好处。[《礼记·大学》原文](https://zh.wikisource.org/wiki/禮記/大學)

**情境与解释：**这不是一位具名人物的历史传记，而是一个用来说明自欺的典型情境。文本把“知道应当怎样”与“真实愿意如此行动”区分开：一个人懂得在人前呈现善行，不代表已经完成诚意的工夫。独处与公开场合之间的落差，是这里的观察重点。

**讨论与边界：**可以追问：行为发生在无人监督时，自己的理由是否仍然成立？文本说内在会显于外，不等于提供了通过表情辨认别人内心的可靠技术。现代借鉴应从自我核查入手，不应据此自称能看穿他人，也不应以“慎独”为由取消合理隐私。

## 2. 爱自己的孩子，却看不到他的缺点

**性质与出处：原典思想论证。**“所谓齐其家在修其身者”段列举亲爱、厌恶、敬畏等关系容易带来的偏向，并用“不知其子之恶”的俗语说明。[《礼记·大学》原文](https://zh.wikisource.org/wiki/禮記/大學)

**情境与解释：**论述没有要求人消除亲情，而是指出感情可能妨碍评价：喜欢的人也会有过失，不喜欢的人也可能有优点。原文把能否看见这种复杂性，放在修身与齐家的衔接处。重点是爱憎与判断之间的张力，而非“亲人都不可靠”。

**讨论与边界：**阅读时可分别列出文本中的情感、判断和行动，检查自己是否把三者混为一谈。这与现代讨论偏见有可比较之处，但相似不等于古书已经提出或验证了某个心理学模型。对儿童的评价也应具体到行为，不能把一次过错变成固定人格标签。

## 3. 引《秦誓》谈容人：有能力的人为何仍可能受阻

**性质与出处：原典引经论证。**“所谓平天下在治其国者”段引用《秦誓》，对比能欣赏别人才能的大臣与嫉妒、阻挠贤能者。[《大学》所引《秦誓》](https://zh.wikisource.org/wiki/禮記/大學)

**情境与解释：**前一种人未必拥有许多专长，却能容纳他人的长处；后一种人因嫉妒而让有才能者无法发挥。两者的差别被放在能否保护子孙与民众的政治后果中讨论。可见全篇谈修养，并不止于个人心情，也涉及掌握任用权的人如何对待别人。

**讨论与边界：**可检查“发现人才”“愿意推荐”“给他实际位置”之间是否存在断裂。这里是借古代政治语言提出伦理要求，不能推成只要宽容就能保证用人成功。现代选任仍需验证能力、明确职责，并给被评价者申辩和复核的机会。

## 4. 社区读书会选协调员

**性质：现代教学示例，情境及人物均为虚构。**借鉴第二、三例的问题意识；以下步骤由本页编写，不冒称《大学》的原有管理程序。

一位发起人倾向选熟悉的朋友，理由是“我了解他的人品”；另一位候选人表达生硬，却有完整的排期与志愿者协调记录。读书会先列出岗位实际需要：按时安排活动、公开记账、回应参与者；再让两人提交同样格式的既往实例。发起人明确自己与候选人的关系，由另一成员主持讨论，记录每项判断依据，并约定一个月后按履职情况复核。

**练习产出：**形成一页“岗位要求—证据—未确定事项”记录，而不是给候选人贴君子或小人的标签。复盘要问：我们是否只替喜欢的人解释失误？有没有忽略不喜欢者的优点？程序安排是现代设计，其效果要从参与者反馈和实际履职评估，不能靠引用经典宣布成功。

核验日期：2026-09-26。原典情境用于理解论证，不视为独立证实的历史事件。
