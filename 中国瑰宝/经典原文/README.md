## 版本与“全文”的边界

这里的“全文”指所列传世版本的正文范围，不是历代所有异本、出土简帛、注疏、译文的全集，也不是已经复原的作者原稿。保留来源使用的简繁与异体字；不为统一外观而自动改写古文。

- 《大学》《中庸》从本次《礼记》底本完整析出，与《礼记》对应篇正文一致；未将朱熹重排及补传混入古文。
- 五经中的“礼”采用常见书目《礼记》；《周礼》《仪礼》是不同作品，不能说成《礼记》的组成部分。
- 《周易》标明经、传层次；易传各部分在来源中有合篇、分篇及嵌入卦文的编排，不能简单以本地文件数等同“十翼”。
- 《尚书》保留通行本包括后世所谓“伪古文”的篇章，并说明其传承与真伪争议；不把58篇都当作商周当时的原始记录。
- 《春秋》收经文；《左传》《公羊传》《穀梁传》作为延伸阅读，不替代经文。
- 《史记》按传世130卷收录，保留后补与传本文字的边界；“太史公曰”等评价属于文本，不能自动当作现代史学定论。

## 怎样按需读取

先看各书摘要与背景，再从目录选择单篇或单卷。需要整部原文时读取各书的 `全文.md`，文件较大；无须为查询一句话加载十部全集。案例页中每个现代场景都标注“现代教学示例”，不冒充古人的制度或真实企业事实。

示例：

```bash
python3 scripts/kb.py resolve culture.classics.lunyu --layer brief
python3 scripts/kb.py resolve culture.classics.daxue --layer detail
python3 scripts/kb.py resolve culture.classics.shiji --layer examples
```

`examples` 层按仓库约定也包含该书全文；只想选读案例时，可按已知目录直接读取案例页。主题间只建立相关推荐，不设置需要自动加载全部经典的依赖。
