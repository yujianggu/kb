## 目标与边界

落实已讨论的分层索引、稳定主题 ID 和按需读取约定。保留原正文及其路径；通用知识不依赖公司子仓库。采用 JSON 元数据及 Python 3 标准库工具，避免新增运行依赖。当前交付为文档知识库，不将教学资料转换成可执行本体。

- [x] 提供生成、校验和按 ID 解析文件清单的工具；索引只保存摘要与地址。
- [x] 验证断链、重复 ID、依赖循环、必需依赖、预算不足、参考资料显式选用及索引过期。

## 文件职责

- `kb.json`：领域注册及可选扩展；`catalog.json`：生成的领域入口。
- 各主题 `topic.json`：元数据唯一来源；各层 `catalog.json`：生成的导航。
- `index/topics.json`：程序专用 ID 地址表，不应整体注入模型上下文。
- `schemas/topic.schema.json`：主题字段约束；`scripts/kb.py`：构建、校验、解析。
- `tests/test_kb.py`：临时知识库上的行为测试。

## 验证与兼容

工具先建立行为测试，再实现。校验所有注册入口、摘要索引同步和依赖图；运行完整测试及实际主题解析。旧文件不删除不搬移，思维模型完整目录与原 README 同层，保持相对链接有效。所有主题的 ID 一经发布不随目录名称变化。JSON 替代设计示例中的 YAML，语义不变。
