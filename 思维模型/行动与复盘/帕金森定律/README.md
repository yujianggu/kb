## 提出者与背景

**提出者／来源：** C. Northcote Parkinson（西里尔·诺斯科特·帕金森）在1955年发表于《经济学人》的同名文章中提出。

**人物或机构简介：** 帕金森是历史学者，曾主持马来亚大学历史系，也推动过历史档案保存。他以讽刺笔法观察行政组织如何增加层级、人员和内部工作；“工作填满可用时间”是这类组织观察中最广为传播的概括。

**归属说明：** 原文中的比例和公式有讽刺性质，不能视为已经验证、适用于所有组织的精确自然定律。
