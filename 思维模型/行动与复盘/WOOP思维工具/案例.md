# WOOP思维工具：案例

> 基于通用知识整理，尚未与视频内容核对。
> 内容类型：通用知识版

**版本与边界：** 采用Wish、Outcome、Obstacle、Plan版本，即愿望、最佳结果、内在障碍、如果—那么计划；依据WOOP官方文字指南。

> 下方原有的三个情境均为假设案例，由本库整理；行动描述不是已发生的效果报告，反例用于说明边界。


## 真实案例：把运动愿望变成应对障碍的计划（2009 年发表）

### 背景与已发生的结果

Stadler、Oettingen 和 Gollwitzer 对德国城市中 256 位 30—50 岁女性开展随机对照研究。两组都得到相同的运动健康信息；实验组还学习心理对照与执行意图，即想清期望结果、现实障碍，再制定行动计划。论文报告，实验组自报的每周中高强度活动时间约为信息组的两倍，差异在四个月随访中维持。这是原研究报告的组间结果，不能写成每个参与者都翻倍。[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/18977113/)

### 具体研究流程：把“知道有益”与“会安排”分开

原研究比较两个条件，信息内容相同，自我调节训练不同，因此不是把接受教育的人与什么都没收到的人简单比较。研究实际实施于 2003—2004 年，2009 年是期刊发表时间。本文核对到的摘要能确认随机对照设计、样本、活动自报指标及四个月随访；没有用摘要补出每位参与者的逐次练习记录。[研究设计与时间](https://pubmed.ncbi.nlm.nih.gov/18977113/)

从设计上看，重要区别在于“额外增加了什么”。如果两个方案连运动场地、补贴和指导时间都不同，即使行为变化，也不能只归因于计划措辞。本例可以帮助读者养成一个阅读习惯：先列共同条件，再列差异条件，最后才看结果。

### 结果口径：组间差异不是个人承诺

“约两倍”比较的是两个研究组的活动时间，不是某个人从原来水平翻倍，也不是疾病风险减半。自报活动量还可能受到记忆和回答方式影响。阅读时应同时保留对象、行为、记录方式和观察期限四项，避免只把醒目的倍数留下。迁移到自己的习惯时，不需要追求相同幅度，先看计划能否让一次原本常被放弃的行动真实发生。

### 与模型的对应（本库分析）

研究直接检验的是 MCII，属于 WOOP 的研究基础；它并非只让参与者想象成功。对照组也知道运动有益，增加的环节是把愿望与障碍联系起来，再把障碍出现时的反应具体化。这里能借鉴的是意图到行动的连接方式，而非用积极想象代替行动。

### 可借鉴步骤

先选自己认可且现实可行的一项活动；写出完成后最有意义的结果；回想上次没有执行时，自己实际遇到了什么内在阻碍；最后写一句“如果出现这个阻碍，那么采取这个小动作”。连续记录是否遇到触发情境、是否执行，而非只记完成天数。若执行了仍无进展，就调整动作，而非追加更强烈的誓言。

记录时把障碍和行动写在一起，能帮助发现计划是否过于抽象。若障碍总是不同，就先观察真实情境，而不是沿用一个与日常生活脱节的固定口号。

### 填写示例：把下班后的拖延写成可观察的障碍

以下是本库编写的应用样表，不是研究参与者的真实日记。假设某人想在晚饭后读完一节课程材料，反复卡在打开手机后不断浏览：

| 项目 | 一次可检查的写法 |
| --- | --- |
| 愿望 | 本周选两个晚上，读完指定小节并写下一个问题 |
| 结果 | 下次讨论时能指出自己理解和没理解的部分 |
| 障碍 | 饭后拿起手机，习惯性进入信息流 |
| 计划 | 如果准备打开信息流，先把手机放到书桌外，打开已标记的小节 |
| 观察 | 触发是否出现、是否执行、执行后读到了哪里 |

这个样表刻意不写“克服懒惰”：它把可重复的时刻与可执行的反应连起来。假如实际记录发现主要问题是照护任务突然增加，就应调整学习时段或目标规模，而不是继续训练放手机。如果已经启动却理解困难，就需要提问、讲解或改变材料；WOOP解决的是启动与执行连接，并不代替学习方法。

复查时可以按失败位置区分三类：没有察觉触发，说明提示不够清楚；察觉但不愿执行，说明动作成本或目标意愿需要重估；执行仍无效，说明所选动作没有击中问题。这样，计划修改有依据，而不是把一次失败当成自律程度的判决。

### 适用限制

本研究活动量来自自报，样本与随访期有限；不能推出长期客观健康改善，也不能把相关比例搬到工作绩效。疾病、伤痛或资源不足不是靠意志就能消除的内在障碍，运动安排仍应适合个人条件。上述操作建议是本库迁移，不是原试验逐字教程。

## 假设练习

> 以下保留原有假设练习，供迁移和反例对照；不属于上述真实事件。

### 1. 生活学习：开始写申请文书（假设）

**情境：** 假设晓文希望周日前写出第一稿，每次却先整理素材几个小时，因为担心开头写得差。

**分析：** 愿望是完成可修改稿，最佳结果是能让同伴给反馈；关键内在障碍是把初稿当成定稿，借准备回避不完美。

**行动：** 她形成计划：“如果我又想先整理更多素材，那么先写一段允许很粗糙的经历描述。”当天实际尝试，记录是否仍卡在第一句，再调整动作大小。

**观察点：** 若应对动作确实执行却不能推进初稿，可换成一个更贴近卡点的动作；计划需要可调整，而非一句永久誓言。

**启示：** 计划回应的是具体障碍，不是泛泛要求努力；若材料确实缺失，也应补充事实，不能只逼自己动笔。

### 2. 工作产品：在会议上提出风险（假设）

**情境：** 假设工程师想在下次评审中清楚提出一项兼容风险，却担心显得自己阻碍进度。

**分析：** 他期待团队及早讨论替代方案，阻碍是紧张时选择沉默；风险本身仍需要日志与条件说明，勇敢发言不能替代证据。

**行动：** 准备好事实后写计划：“如果我担心打断而准备跳过，那么在当前议题结束时说，我有一个影响旧版本的条件需要确认。”会后看是否表达清楚，并征求理解反馈。

**观察点：** 评审后记录触发信号是否被注意到、应对是否能自然执行，再调整表达，而不是仅以他人是否同意来评价自己。

**启示：** WOOP帮助把意愿连接到表达时机；团队若惩罚异议，还需改善制度环境，不能让个人独自承担。

### 3. 误用反例：用愿望替代资源（假设）

**情境：** 假设员工被安排三天完成需要两周的合规审查，主管要求大家做WOOP克服消极心态。

**分析：** 目标受流程和人力限制，主要问题不是内在障碍；把资源缺口心理化会掩盖真实风险。

**行动：** 先列必要步骤和等待时间，协商范围、期限与资源。条件合理后，再对个人容易拖延的某个动作应用WOOP。

**观察点：** 资源调整后再定义一个可控愿望，既能保留个人行动空间，也能避免把制度问题全部推回个人心态。

**启示：** 自我调节工具只能处理它覆盖的部分，不能使不可能的排期可行，更不能被用于责备提出约束的人。
