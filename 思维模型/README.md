每个主题按“先看一张图 → 一分钟大纲 → 明细 → 案例”阅读。通用知识与视频解析分开维护。

**105个主题已补齐：315份独立正文、105张开头示意图，并保留105份SVG源图。** 其中83个为通用知识版，22个为主题参考版（题名原义待核实）。视频解析为0条。

案例页提供有来源的真实案例、模型分析及应用练习。原有103个主题保留扩写详解；新增“价值链分析”与“成本收益分析”分别包含活动配置、方案比较的真实案例，以及质量平台经营汇报与测算练习。

## 怎样选择阅读

想快速理解，先读“一分钟看懂”的图和大纲；要实际使用，再读“明细”的步骤与适用条件，最后读“案例”中的真实事件或研究，比较适用条件，再用假设练习与误用反例检查理解。图均为本库制作，既不是视频截图，也不是作者原图。

“通用知识版”表示采用正文明确的概念或版本；来自视频选题的主题仍未核对视频，独立新增主题注明未关联视频；“主题参考版”表示原题名无法充分确认，正文改为明确标记的相关主题参考，不冒充作者定义。105是目录主题数，不是105个经过科学验证的独立定律。新增“价值链分析”和“成本收益分析”不改变原有110条视频清单。
