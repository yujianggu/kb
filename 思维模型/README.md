## 内容边界

108 个主题中，86 个为通用知识版，22 个为主题参考版（原义待核实）。通用知识版不等于经过科学验证的独立定律。图示是本库制作，案例区分真实事件、教学解释与假设练习。

主题参考版需显式选用；不能把参考主题冒充视频作者原义。本次目录调整未重新核验来源或视频内容。
