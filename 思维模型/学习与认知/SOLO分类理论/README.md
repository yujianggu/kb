## 提出者与背景

**提出者／来源：** 约翰·比格斯（John B. Biggs）与凯文·科利斯（Kevin F. Collis）共同发展，1982 年著作《Evaluating the Quality of Learning》系统阐述 SOLO 分类。

**人物或机构简介：** 两位作者合作研究学习成果的结构与评价。1982 年共同论文分别署名澳大利亚纽卡斯尔大学与塔斯马尼亚大学，将 SOLO 用于分析学生写作的结构复杂度，关注可观察作品的质量，而非给学生贴固定等级标签。

**参考来源：** [1982 年著作：出版商记录](https://doi.org/10.1016/c2013-0-10375-3)；[Biggs 与 Collis：写作结构研究及作者机构](https://journals.sagepub.com/doi/10.1177/000494418202600104)。查阅日期：2026-09-10。
