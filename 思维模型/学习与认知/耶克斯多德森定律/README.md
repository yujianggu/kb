## 提出者与背景

**提出者／来源：** 罗伯特·耶克斯（Robert M. Yerkes）与约翰·多德森（John D. Dodson）于 1908 年发表刺激强度与习惯形成速度的实验研究，构成后来的耶克斯—多德森定律来源。

**人物或机构简介：** 两位作者在该论文中均署名哈佛心理实验室。他们用小鼠进行辨别学习实验，比较不同刺激强度与任务难度下的学习过程；这一共同研究后来成为讨论唤醒、任务难度与表现关系的重要历史来源。

**归属说明：** 原实验并非员工压力调查；后来的倒 U 型概括不可直接当作原论文验证了所有人的统一最优压力。

**参考来源：** [Yerkes 与 Dodson：1908 年论文全文](https://psychclassics.yorku.ca/Yerkes/Law/)；[Wiley：原论文署名与发表信息](https://onlinelibrary.wiley.com/doi/pdf/10.1002/cne.920180503)。查阅日期：2026-09-10。
