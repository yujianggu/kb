## 排序口径

以下是面向一般自学、工作学习与知识分享的**建议使用优先级**，综合预计使用频次、使用范围、能否直接形成练习与反馈、上手成本和已有内容的证据限制安排。基础学习调节与理解方法优先，专门评价框架及状态解释随后；适用情境特殊或证据限制较多的条目放在后面。它不是科学有效性、知名度或实际使用量排名，相邻名次不代表精确差距。

- **预计频次**：高＝可在日常学习与反馈中经常使用；中＝在特定阅读、教学、任务安排或复盘中反复使用；低＝适用情境较专门，或需要更多前提核查。指本页建议的应用机会，未经使用频次调查。
- **使用范围**：广＝跨学习、工作或生活的多类任务；中＝聚焦某些任务类型，可跨学科使用；专＝主要用于特定体验或专门议题。范围广不代表效果更强。
- **按角色调整**：教师可提前选 SOLO，集中读书时可先用 SQ3R，准备演讲时可参考状态与任务条件。无需按名次依次套用全部主题。
- **内容边界**：通用知识版不等于每项主张均已验证，也不表示都是可直接执行的方法。心流、总观效应等概念需区分体验与实践建议；5 个参考主题的题名原义仍待核实，单列且不参与通用条目的优先级比较。

本页调整人工阅读顺序；生成的 `catalog.json` 继续按稳定 ID 排序，不改主题 ID、正文路径或内容状态。以下使用范围与场景依据现有正文整理，实际使用时仍需阅读明细中的条件与限制。
