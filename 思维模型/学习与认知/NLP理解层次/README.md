## 提出者与背景

**提出者／来源：** 罗伯特·迪尔茨（Robert B. Dilts）将格雷戈里·贝特森（Gregory Bateson）的学习层次思想改编为 NLP 中的理解层次。据其本人回顾，1987 年秋已使用身份、信念、能力、行为、环境等标签。

**人物或机构简介：** 迪尔茨是 NLP 领域的作者与培训者，关注学习策略、信念和个人及组织改变。他在贝特森的课程与系统思想影响下发展自己的层次框架；贝特森则是研究沟通、学习和系统关系的人类学家。

**归属说明：** 本目录采用 Dilts 版本，不能把环境到身份的分类直接署名给 Bateson，也不能把作者对层次及神经机制的主张视为已获独立验证。

**参考来源：** [Dilts：A Brief History of Logical Levels](https://www.nlpu.com/Articles/LevelsSummary.htm)。查阅日期：2026-09-10。
