## 提出者与背景

**提出者／来源：** 采用 John Murtagh（约翰·默塔／莫塔）的临床诊断策略五问；其本人文章明确列出这一诊断模型，暂不据此推定最早提出年份。

**人物或机构简介：** 默塔是澳大利亚全科医生与医学教育者，长期在乡村行医并在莫纳什大学任教。他的《General Practice》于1994年首次出版，重视从患者症状、常见问题和实际诊疗经验出发，推动全科医学教学。
