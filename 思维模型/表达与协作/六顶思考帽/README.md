## 提出者与背景

**提出者／来源：** 爱德华·德·博诺（Edward de Bono）提出。其官方机构明确将 Six Thinking Hats 列为他创立的方法，用不同思考角色支持个人和团队的平行思考。

**人物或机构简介：** 德·博诺长期从事思考技能的写作与教育，提出“水平思考”一词，并开发多种创造性思考工具。他的工作重点是把思考变成可练习的方法；六顶思考帽则让团队依次处理信息、感受、风险、价值、创意与过程。

**参考来源：** [de Bono 官方：提出者与方法](https://www.debono.com/)；[De Bono Group：六顶思考帽](https://www.debonogroup.com/services/core-programs/six-thinking-hats/)。查阅日期：2026-09-10。
