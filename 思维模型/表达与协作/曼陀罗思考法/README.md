## 提出者与背景

**提出者／来源：** 松村宁雄（日文：松村寧雄，Yasuo Matsumura）于 1979 年开发 Mandala Chart，即具有中心主题的 3×3 九宫格思考工具。

**人物或机构简介：** 松村宁雄是日本经营顾问，曾任职日本 Olivetti，1979 年独立并创办 Clover 经营研究所。他将九宫格方法用于经营计划与个人规划，进一步发展曼陀罗商务手账，并于 2008 年出任曼陀罗图学会首任会长。

**归属说明：** 此归属针对现代管理工具 Mandala Chart，不是说他创造了传统宗教曼陀罗图式。

**参考来源：** [Mandala Chart 官方：松村宁雄档案](https://mandalachart.jp/wp/matsumurayasuo)。查阅日期：2026-09-10。
