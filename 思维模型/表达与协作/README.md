## 排序口径

以下按一般学习、日常工作与人际协作中的**建议使用优先级**排列。综合考虑预计使用频次、适用范围、能否直接指导行动，以及学习和组织成本。优先排列高频、范围广、容易直接使用的基础方法；解释性模型作为偏差检查工具排在基础行动方法之后。相近条目按基础性与上手成本安排，不代表存在精确的名次差距。

- **预计频次**：高＝日常表达、反馈或评价中经常有使用机会；中＝讨论、规划或关系反馈等特定任务中反复使用；低＝创意改进、公众意见分析或讲师培养等专门任务中使用。描述的是应用机会，不是模型的知名度或实际使用量。
- **适用范围**：广＝可跨工作、学习或生活的多类任务；中＝限于若干任务类型，但可跨行业使用；专＝主要面向某一角色或专门流程。
- **内容边界**：这是基于本库现有摘要与适用边界的编辑判断，未经使用频次调查；通用知识版也不等于科学有效性认证。两项主题参考版单列在末尾，不参与通用模型的优先级比较，其题名频次与范围暂不判断。

本页提供人工阅读顺序；生成的 `catalog.json` 保持稳定 ID 排序，主题 ID、正文路径与内容类型不随本次排序改变。讲师、会议主持人等角色可按自己的任务优先选择 TTT 或六顶思考帽。

## 按场景快速选择

这里是选用建议，不要求每次把多个模型全部套用；“沙龙分享”区分主讲、问答与共创。

| 场景 | 优先选择 | 使用方式与边界 |
|---|---|---|
| 日常交流 | [PREP表达方式](PREP表达方式/一分钟看懂.md)、[FFC赞美法](FFC赞美法/一分钟看懂.md)、[课题分离](课题分离/一分钟看懂.md) | 提建议用 PREP；感谢与肯定用 FFC；讨论责任和选择时用课题分离。倾听、问候等交流不必硬套论证结构。 |
| 向上汇报 | [金字塔原理](金字塔原理/一分钟看懂.md)、[PREP表达方式](PREP表达方式/一分钟看懂.md)、[SCQA序言结构](SCQA序言结构/一分钟看懂.md) | 正式汇报用金字塔组织结论与证据；简短回答用 PREP；需解释问题缘由时用 SCQA。紧急情况先报结论、影响和所需行动。 |
| 沙龙分享：主讲 | [金字塔原理](金字塔原理/一分钟看懂.md)、[SCQA序言结构](SCQA序言结构/一分钟看懂.md)、[黄金圈法则](黄金圈法则/一分钟看懂.md) | 金字塔组织主体，SCQA 交代开场问题；主题涉及目的与价值时再考虑黄金圈。首因与近因效应可辅助检查开场、收尾，不代替内容证据。 |
| 沙龙分享：问答 | [PREP表达方式](PREP表达方式/一分钟看懂.md) | 围绕问题给观点、理由和例子；不确定时明确资料缺口，不为句式完整强下结论。 |
| 沙龙分享：互动共创 | [头脑风暴](头脑风暴/一分钟看懂.md)、[六顶思考帽](六顶思考帽/一分钟看懂.md)、[曼陀罗思考法](曼陀罗思考法/一分钟看懂.md) | 产生点子用头脑风暴；组织不同角度的讨论用六顶思考帽；扩展主题用九宫格。按目的选一种并安排收敛环节。 |
| 团队反馈与复盘 | [乔哈里视窗](乔哈里视窗/一分钟看懂.md)、[FFC赞美法](FFC赞美法/一分钟看懂.md)、[近因效应](近因效应/一分钟看懂.md) | 核对行为反馈、具体肯定贡献，并调取整个周期的记录；不能仅凭最近表现评价全程。 |
| 产品与流程改进 | [头脑风暴](头脑风暴/一分钟看懂.md)、[奥斯本检核表法](奥斯本检核表法/一分钟看懂.md) | 前者扩展方案，后者针对已有对象逐项发问；候选方案仍需验证需求、成本与可行性。 |
