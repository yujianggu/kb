## 提出者与背景

**提出者／来源：** 本库版本主要依据岸见一郎（Ichiro Kishimi）与古贺史健（Fumitake Koga）在 2013 年《被讨厌的勇气》中的普及表达，思想背景属于阿德勒取向。

**人物或机构简介：** 岸见一郎从事哲学与阿德勒心理学研究，古贺史健是日本作家。两人通过哲学者与青年的对话讨论认可、责任、共同体和人生选择，使原本较专业的思想进入大众阅读；应区分他们的解释与历史原著。

**归属说明：** 书中有明确“课题分离”章节，但不足以证明这个固定术语及本库整理的操作步骤均由阿尔弗雷德·阿德勒本人首先提出。

**参考来源：** [钻石社：2013 年原版、目录与作者介绍](https://www.diamond.co.jp/book/9784478025819.html)；[Simon & Schuster：英文版阅读指南](https://www.simonandschuster.net/books/The-Courage-to-Be-Disliked/Ichiro-Kishimi/9781501197277)。查阅日期：2026-09-10。
