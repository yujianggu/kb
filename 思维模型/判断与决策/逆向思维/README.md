## 提出者与背景

**提出者／来源：** 逆向提问属于广泛使用的通用方法，尚未确认覆盖所有用法的单一提出者。与本库失败预演用法相关的项目事前验尸法（premortem），由加里·克莱因（Gary Klein）提出。

**人物或机构简介：** 克莱因是研究自然情境决策的认知心理学家，关注人们在真实工作条件下怎样判断和行动。他把“先假设项目已经失败，再寻找原因”的提问方式发展为具体工具，适合作为逆向思维的一种应用参照。

**归属说明：** 克莱因是相关具体方法的提出者，不能据此认定他发明了所有“逆向思维”；也不将查理·芒格列为通用反向推理的首创者。

**参考来源：** [AHRQ：Premortem Tool](https://www.ahrq.gov/hai/tools/mvp/modules/cusp/premortem-tool.html)；[HFES：Gary Klein人物介绍](https://www.hfes.org/portals/0/documents/hfes_fellow_profiles/gary_klein.pdf?ver=2020-12-23-082604-473)。查阅日期：2026-09-10。
