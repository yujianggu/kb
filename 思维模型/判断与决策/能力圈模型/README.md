## 提出者与背景

**提出者／来源：** 沃伦·巴菲特（Warren Buffett）与查理·芒格（Charlie Munger）是投资领域“能力圈”的代表性实践者与推广者。巴菲特1996年股东信明确讨论了这一概念。

**人物或机构简介：** 巴菲特与芒格长期共同参与伯克希尔·哈撒韦的投资与经营决策，通过股东信和公开交流解释他们的判断原则。能力圈强调理解业务的范围及其边界，是这一实践体系中的重要组成。

**归属说明：** 1996年是可核查的公开阐述时间，不据此断言概念首次产生于该年；“知道自己知道什么”的思想并不限于投资领域。

**参考来源：** [伯克希尔：1996年股东信](https://www.berkshirehathaway.com/letters/1996.html)；[伯克希尔：1996年所有者手册](https://www.berkshirehathaway.com/1996ar/manual.html)。查阅日期：2026-09-10。
