**提出者／来源：** 古希腊亚里士多德（Aristotle）关于科学论证起点的讨论，是第一原理的重要哲学源流；现代商业拆解方法由后世多种实践发展，不由某一家企业独创。

**人物或机构简介：** 亚里士多德是古希腊哲学家，其研究涉及逻辑、自然与知识论等领域。他分析论证如何依赖前提，以及科学知识的起点如何成立；这些讨论为后世理解“从基础出发”提供了哲学参照。

**归属说明：** 不把现代企业家的推广当作哲学概念首创；本库的五步工作方法是应用整理，不是亚里士多德原著中的管理流程。

**参考来源：** [斯坦福哲学百科：Aristotle’s Logic](https://plato.stanford.edu/entries/aristotle-logic/)。查阅日期：2026-09-10。
