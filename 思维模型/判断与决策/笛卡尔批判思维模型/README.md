## 提出者与背景

**提出者／来源：** 本库采用勒内·笛卡尔（René Descartes）《方法谈》（1637）中的方法论线索；“笛卡尔批判思维模型”是现代题名，不是据此确认的原著正式模型名称。

**人物或机构简介：** 笛卡尔是法国哲学家、数学家与自然哲学研究者。他尝试以有序的方法检验知识基础，《方法谈》讨论审慎接受、分解、有序推进与复查，对后来的方法论讨论产生了长期影响。

**归属说明：** 正文的工作检查步骤为本库适配；不能把现代所有批判性思维方法都视作笛卡尔独创。

**参考来源：** [斯坦福哲学百科：Descartes’ Method](https://plato.stanford.edu/entries/descartes-method/)。查阅日期：2026-09-10。
