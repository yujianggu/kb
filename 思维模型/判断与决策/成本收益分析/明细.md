# 成本收益分析：明细

> 内容类型：通用知识版。用于企业项目投入产出判断；操作表与汇报方法由本库整理，未关联来源视频。

## 先明确讨论对象

成本收益分析（Cost–Benefit Analysis，CBA）比较方案的成本与收益。公共政策分析可能采用社会整体视角，企业项目则常先看本企业的财务影响；两者受益主体和计价范围不同。英国财政部《绿皮书》提供公共项目的评价框架，不能将其社会收益或折现率直接作为本公司的现金回报口径。[英国财政部：The Green Book 2026](https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government/the-green-book-2026)

日常所说的项目“投入产出分析”可在这里处理；经济学投入产出分析研究产业间的投入与产出联系，属于另一个模型。[BEA：Annual I-O Accounts](https://www.bea.gov/help/faq/191)

## 一张口径表先于一个回报数字

| 要明确的事项 | 填写要求 |
|---|---|
| 决策问题 | 本次是立项、扩大范围、购买服务还是继续运营？ |
| 分析视角 | 企业、某部门或社会整体；成本由谁承担、收益归谁 |
| 比较基准 | 不新增项目时会发生什么；维持现状也可能继续发生费用与风险 |
| 备选方案 | 最低必要改进、自建、采购、分步实施等可行选择，说明能力差异 |
| 分析范围 | 用户、业务量、流程、组织与项目寿命 |
| 时间与价格 | 期初投入、收益开始时间、分析周期、币种、税前或税后、现价或不变价 |
| 证据等级 | 已实际发生、试点测得、可验证预测、待验证假设 |

比较不同寿命方案时需统一评估窗口，并合理处理续投、残值与退出成本，不能截取各自最好看的几年。实际项目折现率采用企业认可的适用口径；示例参数仅用于理解方法。

## 投入与收益怎样归类

### 投入：现金预算与资源占用分别说明

一次性投入可能包括开发采购、集成、数据迁移、培训及切换；持续投入包括许可、计算资源、维护、运营、业务标准维护和再培训。还要检查扩容、替换、退出及营运资金变化。

已有人员工资不会因项目变化时，不凭工时分摊自动形成新增现金支出，但占用这些人员会影响其他工作，应单列容量与机会成本。已经发生且不可收回的投入，可在历史复盘中披露，不能作为继续投入的理由。财务投资分析关注未来增量现金流；折旧本身不作为现金流重复扣除，相关税款变化则需按实际口径处理。[ACCA：Investment appraisal](https://www.accaglobal.com/hk/en/student/exam-support-resources/prodipsust-study-resources/technical-articles/investment-appraisal.html)

### 收益：四类结果分别展示

| 类型 | 可使用的证据 | 计入现金回报的条件 |
|---|---|---|
| 现金支出减少 | 合同、采购、外包、加班费用变化 | 确实因方案少支付，且扣除替代支出 |
| 工作容量释放 | 业务量、有效采用比例、单次净节时 | 只有转化为实际少支出或增量现金贡献时，才计入现金回报 |
| 业务质量改善 | 同口径返工、报废、售后支出等 | 确认业务量、价格与产品结构影响，剔除重叠费用 |
| 风险降低 | 风险发生可能性、暴露量与损失范围 | 可做情景或期望损失分析，但不能当成保证到账的节省 |

以下是本库的工作估算方式，参数均需要实际证据：

- 年释放工时 = 年业务量 × 有效采用比例 × 单次净节约时间。单次净节约时间应扣除新增录入、复核等负担。
- 期望损失改善 = 基准方案期望损失 − 新方案期望损失。单事件简化模型可用“发生概率 × 发生时损失”，不能直接用最坏损失代替期望值。

工时价值和同一批工时带来的外包费减少不能重复计入；同一质量事件的返工费、损失总额与索赔回收也需去重。新增销售额要扣除相应增量成本后，才能用于财务回报计算。

## 指标与公式

本文中 `B_t` 为第 t 期的增量收益，`C_t` 为同一期增量成本，`r` 为与现金流周期一致的折现率，`t=0` 为现在。财务计算中 B、C 使用现金口径；货币化的非现金效益另列，不混入财务回收期。

| 指标 | 本文使用的定义 | 用途与限制 |
|---|---|---|
| 未折现净收益 | ΣB_t − ΣC_t | 给定周期总额，未考虑时间价值 |
| 简单项目 ROI | (ΣB_t − ΣC_t) ÷ ΣC_t × 100% | 本文明确采用“周期总成本”为分母；不是年化回报，也不等同于财务报表中的 ROI 口径 |
| 未折现收益成本比 | ΣB_t ÷ ΣC_t | 例如 1.3 表示每 1 元成本对应 1.3 元收益；在完全相同口径下，对应简单 ROI 30% |
| 净现值 NPV | Σ[(B_t − C_t) ÷ (1+r)^t] | 将各期增量现金流折算到现在；正值仍取决于假设和实施约束 |
| 折现收益成本比 BCR | Σ[B_t ÷ (1+r)^t] ÷ Σ[C_t ÷ (1+r)^t] | 分子分母必须同口径且成本现值为正，比较规模不同方案时不能只看比例 |
| 静态回收期 | 累计未折现净现金流首次覆盖初始投入所需时间 | 忽略时间价值及回收后收益；不足以单独决定项目取舍 |

ROI 存在不同定义，汇报必须写明分母与周期。BCR 的公共评价定义可参考[《绿皮书》](https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government/the-green-book-2026)；企业应用需重新确认现金范围。

只有初始一次性投入、此后每期净现金流为相同正数，且持续足够长时，静态回收期才能简化为“初始投入 ÷ 每期净现金流”。不均匀时逐期累计；期内插值要说明现金均匀发生的假设。折现回收期则累计折现现金流；评估期内未回收应直接说明。[ACCA：Payback and discounted payback](https://www.accaglobal.com/gb/en/student/exam-support-resources/foundation-level-study-resources/ffm/ffm-technical-articles/discounted-payback.html)

成本与收益应保持名义或实际价格、税务与折现口径一致。正式测算如涉及融资现金流，需先由财务确定项目或股东视角，避免与折现率重复处理融资成本。

## 敏感性分析：结论在什么条件下改变

以下为本库建议的检查方法。

1. 选择最不确定且影响大的参数，如有效采用比例、单位节时、实际费用减少、建设费与上线时间。
2. 单因素分析一次只改一个参数，找出哪个因素最影响结论；“上下浮动20%”只是练习，不是置信区间。
3. 情景分析同时改变有关联的假设，例如延期、推广慢与费用上升，不给乐观组合冠以“实际预测”。
4. 求转换点：收益最低要达到多少，NPV 才不为负？与试点证据比较，判断余量。
5. 说明下一步获取什么证据、何时重算、什么条件触发缩减或调整。

必要的安全、质量与合规约束先满足，再比较可行方案。难以货币化的效果仍应展示；对达到相同最低要求的方案，也可比较达到要求的成本与可靠性。

## 向上级汇报的一页结构

| 内容 | 应回答的问题 |
|---|---|
| 推荐与范围 | 建议选哪个方案，解决什么问题，适用于哪里？ |
| 增量投入 | 相比基准多花多少钱、占用什么资源、何时发生？ |
| 收益与证据 | 哪些已验证，哪些预测，哪些只能作为业务效果单列？ |
| 回报与时间 | 给定周期的净收益、ROI、NPV与回收期分别是什么？ |
| 关键假设 | 哪个因素最影响结果，低于什么条件就需要调整？ |
| 决策与验证 | 需要批准什么、谁验证收益、何时复核？ |

先用[价值链分析](../../商业与产品/价值链分析/README.md)解释收益如何产生，再用本模型比较是否值得投入，最后用[金字塔原理](../../表达与协作/金字塔原理/README.md)组织表达。必要时结合[机会成本](../机会成本/README.md)、[沉没成本](../沉没成本/README.md)和[PDCA](../../行动与复盘/PDCA循环/README.md)。
