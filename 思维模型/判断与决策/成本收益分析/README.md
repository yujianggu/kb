# 成本收益分析

[返回本分类](../README.md) · [返回总导航](../../README.md)

用途索引：判断与决策（编辑分类）。用于项目立项、方案比较、预算取舍及经营汇报，回答“投入多少、收益是什么、何时回本、条件变化后是否仍值得做”。

工作汇报中的“投入产出分析”可从本主题进入。此处讨论项目成本收益，不是研究产业之间投入与产出联系的经济学投入产出模型。

## 提出者与背景

**提出者／来源：** 成本收益分析由工程经济、福利经济学和公共评价实践逐步发展。朱尔·迪皮（Jules Dupuit）1844年对公共工程效用的研究，是常被追溯的重要早期来源。

**人物或机构简介：** 迪皮是法国土木工程师与经济学研究者，将公共工程、收费和效用问题联系起来。他对工程价值衡量的讨论，为后来成本收益评价提供了早期思路；现代折现、风险与企业回报方法仍经历了后续发展。

**归属说明：** 迪皮是重要先驱，不能把本库的 ROI、回收期和敏感性分析整套工具都归为他一次提出。

**参考来源：** [OECD：成本收益分析的早期发展](https://www.oecd.org/content/dam/oecd/en/publications/reports/2006/01/cost-benefit-analysis-and-the-environment_g1gh604e/9789264010055-en.pdf)；[Larousse：Jules Dupuit人物介绍](https://www.larousse.fr/encyclopedie/personnage/Jules_Juv%C3%A9nal_Dupuit/117438)。查阅日期：2026-09-10。

## 内容状态与范围

- 内容类型：**通用知识版**。以企业内部项目决策为应用场景，区分财务回报与更广义的成本收益。
- 来源：英国财政部、ACCA、美国经济分析局及美国能源部公开文字资料，查阅日期为 2026-09-10。
- 三份正文及 PNG、SVG 示意图已补齐；图由本库制作，非来源机构原图。
- 本主题为工作需要新增，未关联来源视频，不改变原有 110 条视频清单；未进行视频解析。
- 质量平台案例中的金额、折现率与效果均为假设，计算可复核，不代表本公司财务口径或经营结果。

准备实际汇报时，先确认明细中的比较口径，再参照案例填写数据；不要直接沿用示例收益和折现率。
