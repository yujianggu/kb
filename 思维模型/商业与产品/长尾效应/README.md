## 提出者与背景

**提出者／来源：** Chris Anderson（克里斯·安德森）于2004年在《WIRED》发表《The Long Tail》，系统传播数字商业的长尾观点。

**人物或机构简介：** 安德森是科技与商业作者，曾任《WIRED》主编。他通过《长尾理论》《免费》等著作讨论数字化对商业的影响，随后也参与机器人创业；其长尾论述关注数字渠道如何连接大量小众供给与需求。

**归属说明：** 安德森提出的是商业解释与经营观点，并非发明统计分布中的长尾现象。
