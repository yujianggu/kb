## 提出者与背景

**提出者／来源：** 电通（Dentsu）于2004年提出 AISAS，将搜索（Search）和分享（Share）纳入消费者行为分析。

**人物或机构简介：** 电通源于1901年创办的日本广告业务，逐步发展为跨市场的传播与营销服务集团。AISAS 来自其对互联网环境下消费者行为的观察，突出消费者主动查找信息及传播体验对购买路径的影响。
