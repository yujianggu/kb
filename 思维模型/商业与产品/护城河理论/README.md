## 提出者与背景

**提出者／来源：** 经济护城河的投资与经营比喻主要由 Warren Buffett（沃伦·巴菲特）传播；本库采用其2007年伯克希尔股东信对持久竞争优势的明确论述。

**人物或机构简介：** 巴菲特是长期经营伯克希尔·哈撒韦并撰写股东信的投资者。他在信中讨论资本配置、企业经济特征与管理，强调优秀企业需要能抵御竞争的持久优势，并区分企业自身优势与依赖个别明星管理者的表现。

**归属说明：** 2007年是本页采用的可查论述年份，不是护城河比喻的首次出现年份，也不意味着所有后来的分类都由巴菲特提出。
