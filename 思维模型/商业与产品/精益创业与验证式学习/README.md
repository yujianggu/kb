# 精益创业与验证式学习

[返回商业与产品](../README.md) · [思维模型总导航](../../README.md)

当团队不知道客户是否需要、愿意购买或持续使用某个产品时，用有限投入取得能改变决策的证据。本主题讲解从假设到实验、测量与继续／转向／停止的完整过程。

## 来源与内容定位

精益创业（Lean Startup）由Eric Ries提出并推广；验证式学习（Validated Learning）是其核心概念之一。它将创业中的学习作为管理对象，以实验检验商业假设。这里的“验证”是特定条件下得到证据支持，不是永久证明整个商业模式成立。

本文依据[精益创业官方方法说明](https://theleanstartup.com/principles)解释核心概念，并借鉴[Strategyzer实验卡](https://www.strategyzer.com/library/validate-your-ideas-with-the-test-card)组织假设、测试、测量和门槛。两者来源分开，不将实验卡归为Eric Ries原作。

- 内容类型：通用方法；不代表经过独立科学验证的成功定律。
- 更新及来源查阅：2026-09-20；来源支持范围详见[来源与边界](来源.md)。
- 操作步骤、模板及教学案例由本库整理；案例数字全部是假设，未实际开展访谈、试点或销售。
- 主题ID：`thinking.lean-startup`。本主题独立于视频合集，未做视频解析。
