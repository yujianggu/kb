## 提出者与背景

**提出者／来源：** 迈克尔·波特（Michael E. Porter）于1979年在《哈佛商业评论》文章中提出五力框架。

**人物或机构简介：** 迈克尔·波特是哈佛商学院的战略与竞争研究学者，研究企业如何选择竞争位置、组织活动并维持优势。他的五力与价值链框架分别连接行业结构和企业内部活动，为经营选择提供了不同层次的分析工具。

**参考来源：**
