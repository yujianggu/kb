# 因果回路

[返回本分类](../README.md) · [返回总导航](../../README.md)

用途索引：系统与问题分析（编辑分类）。用于解释反复发生的问题、经营趋势与措施的长期影响。

## 提出者与背景

**提出者／来源：** 因果回路图（Causal Loop Diagram，CLD）属于系统动力学的常用工具，由多位研究者发展。Jay W. Forrester 是系统动力学的奠基者；John D. Sterman 对因果回路的规范表达、建模与管理应用有系统阐述。本页不将学科奠基者直接认定为这类图示的唯一发明人。

**人物或机构简介：** Forrester（1918—2016）是 MIT 学者，早期从事数字计算与控制研究，后来创立系统动力学，将反馈和动态建模用于理解企业及社会系统。Sterman 是 MIT 的系统动力学研究者与教育者，著有《Business Dynamics》，研究复杂系统中的决策与学习；该书第5章介绍因果回路图。

**归属说明：** 多人发展或推广。这里介绍的是系统动力学中的反馈图示，不能与统计因果识别中的有向无环图混为一谈。
