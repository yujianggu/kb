## 提出者与背景

**提出者／来源：** 王东岳在《物演通论》中提出“递弱代偿”哲学主张。东岳哲学学会所转载作者简介记录了 1998 年初版、2003 年修订版及 2002 年专题讨论；这些是该学会提供的出版与传播线索，不在此进一步断言术语的最早成稿时间。

**人物或机构简介：** 王东岳笔名子非鱼，曾受医学训练，后转向独立哲学研究，著有《物演通论》《知鱼之乐》等。他尝试在同一哲学体系中讨论自然、精神与社会存在；本页介绍其思想来源，不把哲学体系当作已经获得经验科学证明的规律。

**归属说明：** 简介来源为研究传播该思想的学会所转载资料，应与独立学术评价区分；知识库的依赖检查练习也不是作者原著步骤。
