## 提出者与背景

**提出者／来源：** 野中郁次郎（Ikujiro Nonaka）在 1994 年组织知识创造论文中系统阐述四类知识转换；他与竹内弘高（Hirotaka Takeuchi）在 1995 年《创造知识的企业》中进一步发展和传播这一理论。

**人物或机构简介：** 野中郁次郎与竹内弘高是研究组织知识创造与企业创新的日本管理学者。他们通过企业研究，讨论经验性知识如何被表达、共享并转化为新产品及组织能力，使知识管理超出资料收集与信息存储的范围。

**归属说明：** 本页采用隐性与显性知识四种转换的版本；1994 年是所引论文的发表年份，不等于相关思想第一次出现。

**参考来源：**
