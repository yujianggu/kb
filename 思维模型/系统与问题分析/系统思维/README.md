## 提出者与背景

**提出者／来源：** 系统思维是多学派的方法家族，不能全部归给一位作者。本页采用的反馈、存量、流量和时滞视角，主要属于杰伊·福雷斯特（Jay W. Forrester）在 20 世纪 50 年代发展起来的系统动力学传统；《Industrial Dynamics》于 1961 年出版。

**人物或机构简介：** 福雷斯特是麻省理工学院的计算机与系统动力学先驱，早期从事数字计算和反馈控制。他把工程中的反馈与仿真方法用于工厂、供应链和城市研究，说明组织自身的决策规则也可能造成波动，为理解复杂经营行为提供了工具。

**归属说明：** 上述年份指系统动力学的发展节点，不是整个系统思维的诞生时间；本页不将一般系统论、控制论和组织学习的贡献都归入一人名下。

**参考来源：**
