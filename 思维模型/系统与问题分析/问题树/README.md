## 提出者与背景

**提出者／来源：** 本页采用围绕核心问题绘制原因与后果的 Problem Tree Analysis。ODI 于 2009 年发布的工具说明指出它已在发展机构项目规划中得到广泛使用；本次未据此确认单一首创者。

**人物或机构简介：** ODI 是从事全球发展研究、政策分析和咨询的智库，其工作连接研究证据与实际政策选择。它发布的方法工具帮助研究者和项目参与者梳理问题、交流证据并制定行动；本页的问题树版本来自其公开规划工具说明。

**归属说明：** ODI 是所用版本的发布与传播机构，不是已经证明的发明机构；本页因果问题树也不等同于咨询中所有议题树。
