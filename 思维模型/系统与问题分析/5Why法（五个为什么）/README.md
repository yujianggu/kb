## 提出者与背景

**提出者／来源：** 本页采用丰田生产方式中的 Five Whys。大野耐一（Taiichi Ohno）是可核查的重要阐述者与实践推动者，LEI 词典引用其1988年英文版著作中的停机例子。本次未据这些资料断言他是唯一首创者，也未将常见的“丰田佐吉发明”说法作为已证实结论。

**人物或机构简介：** 大野耐一（1912—1990）是丰田生产方式的重要奠基者，在丰田英二支持下参与建立生产体系和准时化的基本框架。丰田汽车在生产实践中强调发现异常、改善工作与防止复发；5Why 应放在这样的现场问题解决背景下理解，而不是脱离事实的语言追问游戏。

**归属说明：** 多人发展或推广。本库采用可追溯的丰田实践与大野耐一阐述，不给追问方法指定缺乏证据的唯一发明时间。
