## 提出者与背景

**提出者／来源：** “道”“器”的经典语境可追溯到《周易·系辞》，但本次未确认“道、法、术、器”作为现代管理四层框架的唯一提出者或统一古典出处。本页目的、方法、动作与工具的四层定义是知识库整理。

**人物或机构简介：** 本页采用的文字来源是教育云教育百科收录的《教育大辞书》词条，由傅元龙撰写，标注日期为 2000 年 12 月。该条目解释传统哲学中道与器、形上与形下的关系，为辨认古典概念与现代工作类比的差异提供背景。

**归属说明：** 傅元龙是所引辞书条目的撰写者，不是已确认的“道法术器”模型提出人；不能将古典语句直接当作现代四层流程的历史证据。
