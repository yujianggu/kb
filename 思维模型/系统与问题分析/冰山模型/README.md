## 提出者与背景

**提出者／来源：** 本页采用事件、模式、结构、心智模式四层系统思维冰山。Kambiz E. Maani 与 Robert Y. Cavana 的《Systems Thinking, System Dynamics》2007 年第二版及授权改编文章明确展示这一版本；本次未确认其唯一首创者。

**人物或机构简介：** Maani 研究组织、领导力与系统方法，Cavana 研究系统科学和系统动力学。两人合著的教材把问题结构化、因果回路、动态建模和组织学习联系起来；冰山层次帮助读者由孤立事件转向观察长期模式及其形成条件。

**归属说明：** 这里的归属限定为四层版本的阐述来源，不能直接套用胜任力冰山、文化冰山或心理治疗冰山的作者。

**参考来源：**

- [Maani、Cavana：Systems Methodology，含作者简介与版本说明](https://thesystemsthinker.com/systems-methodology/)
