## 提出者与背景

**提出者／来源：** 罗伯特·默顿（Robert K. Merton）在 1968 年《科学中的马太效应》中命名并阐述这一现象。其 1988 年后续论文重申：原文大量依赖哈丽雅特·朱克曼（Harriet Zuckerman）的研究，本应共同署名。

**人物或机构简介：** 默顿是哥伦比亚大学社会学者，研究科学共同体的奖励、声望和知识传播。朱克曼通过对诺贝尔奖得主的访谈研究科学合作与精英形成，为这一概念提供关键经验材料；两人的贡献共同帮助揭示科学认可如何形成累积优势。

**归属说明：** 1968 年论文的署名与实际知识贡献应分别说明。圣经是命名的比喻来源，不能把其作者视为现代科学社会学模型的提出者。

**参考来源：**

- [Merton：1988 年后续论文，含共同署名说明](https://garfield.library.upenn.edu/merton/matthewii.pdf)
