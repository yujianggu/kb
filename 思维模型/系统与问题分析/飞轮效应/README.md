## 提出者与背景

**提出者／来源：** 本页采用吉姆·柯林斯（Jim Collins）在《Good to Great》（《从优秀到卓越》）中发展的组织管理飞轮概念；作者官网明确列出这一归属。

**人物或机构简介：** 柯林斯是研究企业与组织长期表现的管理作家和教师，曾在斯坦福商学院开展研究与教学，1995 年建立自己的管理研究机构。他通过企业比较研究讨论领导力、人员选择和持续积累，飞轮是其解释渐进突破的重要比喻。

**归属说明：** 这里确认的是管理概念的来源，不是机械飞轮的发明者；本页具体反馈图和指标表为知识库应用整理。
