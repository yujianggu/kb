## 提出者与背景

**提出者／来源：** 5W1H 是新闻写作、调查和任务澄清中使用的提问框架，本次未确认单一首创者。鲁德亚德·吉卜林（Rudyard Kipling）1902 年《原来如此的故事》中的六位仆人诗，是六类提问的可核查早期助记表达。

**人物或机构简介：** 吉卜林是英国诗人、小说家和记者，1907 年获诺贝尔文学奖，代表作包括《丛林之书》。记者经历与好奇心也进入他的文学表达；六位仆人的形象使“什么、为何、何时、如何、何处、何人”更容易记忆。

**归属说明：** 诗作提供文学表达的出处，不能据此认定吉卜林发明了现代管理版 5W1H；也不要与丰田的五个为什么混淆。
