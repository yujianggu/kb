# 企业与机构

每个研究对象独立建目录，按[统一调研框架](../调研框架.md)积累资料。机构类型不同，评价标准也应相应调整。

| 对象 | 类型 | 当前研究重点 | 资料 |
|---|---|---|---|
| Y Combinator（YC） | 创业投资与加速机构 | 自身经营模式、早期创业方法、经验沉淀与适用边界 | [调研记录](YC/README.md) |
| 丰田 | 汽车制造与出行 | 生产系统、异常管理、改善、人才培养与治理缺口 | [调研记录](丰田/README.md) |
| 亚马逊 | 电商、云计算与平台服务 | 客户价值、长期投入、能力产品化与平台权力 | [调研记录](亚马逊/README.md) |
| 华为 | 信息通信与智能设备 | 长期研发、多业务协同、集体治理与经营韧性 | [调研记录](华为/README.md) |
| 丹纳赫（Danaher） | 科学与技术业务集团 | DBS、并购整合、组合重塑与管理方法复用 | [调研记录](丹纳赫/README.md) |
| Costco | 会员制零售 | 价格信誉、有限选品、周转效率与会员关系 | [调研记录](Costco/README.md) |
| 伯克希尔·哈撒韦 | 多元化控股与保险 | 分权经营、集中资本配置、承保纪律与继任 | [调研记录](伯克希尔哈撒韦/README.md) |
| 微软 | 软件、云与平台服务 | 成熟企业转型、产品组合、AI 投入与安全治理 | [调研记录](微软/README.md) |
| Inditex／Zara | 服装设计、零售与供应链 | 需求反馈、集中物流、库存协同与供应链边界 | [调研记录](Inditex-Zara/README.md) |

新增对象时更新此表；形成可比较案例后，再链接到[跨企业专题](../跨企业专题/README.md)。
