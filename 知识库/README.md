# 知识库

研究**服务 AI 大模型的知识库**，关注业务资料如何成为可检索、可回查、可维护的任务依据。当前包括 LLM／AI Coding 背景下的介绍与概要，以及提供方公开的 RAG 构建方案；不收录纯文档协作工具，也不代表任何公司的内部知识管理实践。

## 概要

模型具备通用语言与推理能力，却不会自动获得你的私有资料、最新项目状态和业务授权。知识库连接模型与具体任务：将文档、代码、规则和决策记录组织成可供运行时读取的证据，说明来源、版本、适用范围及访问条件。

在 AI Coding 中，它帮助 Agent 理解项目约定、接口契约、设计理由和验证方法；在持续研究中，可以把原始材料整理为有来源的 Wiki；在关系密集的业务中，可以结合知识图谱与本体。RAG、Wiki 和图谱是可组合的方式，不是必须逐级升级的路线。

建设目标是**在任务需要时提供适用、可回查的知识，并支持安全行动与持续维护**。检索命中不等于答案正确，知识库也不自动保证实时性或获得执行授权。知识供给是重要瓶颈，但模型能力、工具可靠性和业务验收仍需共同满足。
