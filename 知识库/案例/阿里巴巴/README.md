# 阿里巴巴：阿里云百炼 AI 知识库方案

提供方：阿里巴巴／阿里云。产品：大模型服务平台百炼（Model Studio）的知识库与知识检索服务。查阅日期：2026-10-12。

本案例研究提供方公开的构建能力，不代表阿里巴巴内部知识库的实施情况。下文将**官方能力**与**研究建议**区分；未部署、未进行性能或效果实测。

## 定位与架构

适合研究托管式 RAG：把业务资料处理成可检索证据，再将证据交给大模型生成回答。知识库承载文档与索引，检索服务负责召回与排序，业务应用负责用户交互和最终回答约束。它与面向人工编辑的文档协作工具用途不同。

官方创建指南列出文档搜索、数据查询、图片问答和音视频搜索类型。首期建议从**文档搜索**开始，确认正文、表格及扫描件的解析质量，再扩展其他类型；不同类型的接口能力不能直接互推。[创建知识库](https://help.aliyun.com/zh/model-studio/rag-knowledge-base)

建议链路：受控原文 → 解析 → 切片与向量化 → 文档索引 → 知识检索服务 → 获得证据 → 大模型回答与来源展示。

## 官方确认的关键能力

- **解析与索引**：创建流程提供多种文档解析选项及切分策略；可根据资料结构选择解析方式。[创建指南](https://help.aliyun.com/zh/model-studio/rag-knowledge-base)
- **切片与嵌入**：官方列出智能、长度、页、标题、正则及符号切分。切分策略应与文档结构匹配，而不是直接沿用统一长度。[切片与向量化](https://help.aliyun.com/zh/model-studio/rag/chunking)
- **检索与重排**：知识检索服务支持多知识库联合检索，配置向量／关键词召回、重排、阈值与标签过滤，并可查看命中切片及来源。该页特别区分了底层单库检索接口与带重排的检索服务，接入时需要选择正确入口。[知识检索](https://help.aliyun.com/zh/model-studio/rag-knowledge-retrieval)
- **程序化维护**：官方 API 指南给出文档搜索类知识库的创建、导入与索引任务操作；它不是所有知识库类型的统一操作说明。[知识库 API 指南](https://help.aliyun.com/zh/model-studio/rag-knowledge-base-api-guide)

## 推荐构建流程（研究建议）

1. **准备受控语料**：先选一个业务主题；为每份文档记录来源、版本、生效日期、责任人和访问范围。过期资料不与现行规则无标记混合。
2. **验证解析**：抽查扫描 PDF、表格和图文文档；验证单位、表头与条件是否保留。解析失败先修复数据，再调整模型。
3. **构建索引**：用真实问题比较标题切分与其他策略。保留文档身份及定位信息；改变解析或嵌入配置后重新验证索引。
4. **单独检验检索**：先查看正确证据能否被召回，再比较重排与阈值设置。不要把回答流畅程度当成证据命中的证明。
5. **接入回答链路**：要求回答引用可回查的文档；无充分证据时说明缺失，不把推测表述为制度事实。引用对应性与拒答逻辑由应用验收。
6. **上线维护**：验证更新和删除在索引中的实际生效结果；记录配置、问题、命中片段、回答和人工判定，形成回归集。

## 适用场景与限制

**选型建议**：已使用阿里云、希望以托管服务组织业务问答的团队，可将百炼纳入候选；最终需以本方中文语料、部署地域、权限要求和运行成本验证。

- **地域与接口**：所查 API 指南限定中国站北京、国际站新加坡，并只适用于文档搜索；国际站页面还存在历史账号访问限制。应按实际账号核验，不将国际站与中国站说明合并为同一承诺。[API 指南](https://help.aliyun.com/zh/model-studio/rag-knowledge-base-api-guide)、[国际站知识库指南](https://www.alibabacloud.com/help/en/model-studio/rag-knowledge-base)
- **配置变更**：创建指南称部分配置可调整并重建索引，切片指南及容量页却写有创建后不可更改的限制。这些官方页面存在表述差异，本文不作统一承诺；迁移前须在目标控制台或向官方确认。[创建指南](https://help.aliyun.com/zh/model-studio/rag-knowledge-base)、[容量与限制](https://help.aliyun.com/zh/model-studio/rag-knowledge-base-specifications)
- **权限治理**：业务空间与 API 操作权限不能证明源系统逐文档访问控制自动继承。标签过滤仅作为检索功能记录，是否能用于安全隔离必须另行验证；应用端授权、敏感语料准入和删除验收仍需设计。
- **费用与效果**：解析、嵌入、检索、重排及生成应分别测算；本文不提供固定价格、吞吐或准确率。正式采购前重新核对当期计费与限额。

## 可借鉴点

将“知识数据管理”“检索服务”“生成应用”分开验收。即便采用托管平台，仍保留独立原文、来源元数据和测试集，便于迁移及定位问题。进一步证据范围见[来源与适用边界](来源与适用边界.md)。
