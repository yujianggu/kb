# AI Coding 项目 Wiki：接口变更与知识复用

**本库原创教学示例。** 以下项目、文件、接口、身份与记录均为虚构，不是 Karpathy 的实际项目，也不是本仓库实现；目录及页面格式是演示建议，未运行代码或数据库。

## 场景与初始证据

虚构项目 Atlas 的资料分散在接口契约、鉴权代码、设计记录和测试说明中。团队希望 Agent 修改权限接口时，少重复探索，同时保留可核验依据。

| 教学来源 ID | 材料 | 可支持的结论 | 不足之处 |
|---|---|---|---|
| S-contract-v1 | 旧版权限接口契约 | 请求和响应定义 | 不解释设计理由 |
| S-code-r1 | 提交 r1 的鉴权代码 | 该提交中的实际实现 | 不证明它满足全部业务要求 |
| S-decision-01 | 经团队确认的设计记录 | 为什么区分业务角色 | 不证明今天仍是相同实现 |
| S-checks-r1 | 对 r1 的测试记录 | 已验证的任务与边界 | 不覆盖后续版本 |

为便于演示，r1、r2 是版本占位名称，不是真实 Git SHA。实际系统需保存可解析的提交版本及具体文件／符号定位。

## 第一次整理：形成少量有明确用途的页面

建议先建立项目概览、鉴权模块页和设计决策页。每页说明：它解决什么问题、依据哪些来源、适用哪个版本、还有哪些未确认项。

模块页不复制全部鉴权代码，而是提供读取入口、接口约束、责任边界和验证方法。决策页只整理已经确认的理由；无法找到理由时写成问题，不替团队补造历史。

关联也需要说明依据，例如“模块页中的角色规则引用 S-decision-01”；不能因为两个页面都提到权限，就推定它们表达相同规则。

## 第一次任务：新增租户范围

需求：新版权限请求增加租户范围。以下只是知识维护步骤，不是鉴权方案或代码实现建议。

| 阶段 | Agent／维护流程应做什么 | 形成的记录 |
|---|---|---|
| 读取上下文 | 从模块摘要定位契约、实现和设计依据 | 本次读取的页面及来源版本 |
| 判断影响 | 识别调用方、契约与测试入口，检查现有知识缺口 | 影响清单和待确认问题 |
| 修改与验证 | 在已授权范围内实施，并执行实际任务要求的检查 | 代码差异与检查结果 |
| 提出知识修订 | 说明哪些旧结论被替代，哪些仍成立 | 候选修订与来源对应 |
| 核对与发布 | 由约定流程确认关键事实和影响，再更新页面 | 审查记录、页面版本和索引 |

设教学中的目标版本为 r2。新契约与代码观察成为 S-contract-v2、S-code-r2；新版检查结果单独记录。旧来源可以作为历史保留，但默认回答 r2 问题时不得将 r1 契约混入现行答案。

## 一个建议的修订记录（教学模板）

```text
页面：atlas.auth-overview
用途：定位租户范围权限接口的资料与验证入口
目标版本：r2
结论：新版契约包含租户范围；具体字段定义以 S-contract-v2 为准
实现依据：S-code-r2 中对应处理位置
设计理由：仍引用 S-decision-01；新增租户范围的理由需要新决策确认
替代项：r1 请求字段说明被新版契约替代
验证范围：仅记录实际完成的检查，不写“全部安全”
发布条件：确认新契约、实现及调用方影响后进入可信页面
```

模板刻意区分契约、实现、设计理由和验证：修改成功并不能自动证明新决策合理，测试通过也不能证明未覆盖场景安全。

## 第二次任务：解释旧客户端为何失败

Agent 首先在 Wiki 发现：当前目标为 r2，接口契约存在一次范围字段变化；随后读取版本差异和当前代码，检查旧客户端实际请求。Wiki 缩小调查入口，不直接提供未经验证的故障结论。

若确认这是契约迁移问题，可提出一个带复现条件的排查说明，补到现有接口迁移页面。若未复现，只保留为任务假设。一次调查不应把“所有旧客户端都会失败”写成项目规则。

这次工作复用了第一次的资料定位、版本映射和验证入口；新增的是经过核对的排查知识，而不是又复制一份全部资料。

## 冲突与撤销演练

- **文档与代码冲突**：分别记录契约要求和实际行为，判断哪一方需要更正；不能默认代码就是业务标准。
- **测试记录过期**：r1 的通过记录保留历史意义，不能用于证明 r2 的接口。
- **来源需要撤权**：检查它是否进入摘要、综合页、索引及缓存；衍生知识不应因为改写了措辞就绕过访问限制。
- **知识修订失败**：保留候选差异，修复来源或链接后重新核对；不让部分更新被误认为完整发布。

## 可以验收什么

用两轮任务检查：Agent 是否找到正确版本，是否保留必要条件，变更能否触发受影响页更新，回答是否回查原文，未确认结果是否被挡在可信知识层之外。

衡量读取和维护的总投入，而不只统计页面数或一次问答的 token。该示例用于说明流程，没有提供实测收益。返回[方案正文](README.md)。
