# LLM Wiki 方案摘要

Karpathy 提出的 LLM Wiki 在原始资料与问答之间设置持续维护的 Markdown 知识层，积累摘要、关联和综合结果。正文在作者模式之外，提供本库设计的页面契约、摄取／查询／维护闭环、冲突和过期处理、受控回写及试点评测，附 AI Coding 两轮任务教学案例。

结合知乎专栏与问答，补充高频综合页和原文检索协作、企业结构化事实分工、中文与并发写入检查，并说明社区自报数据的可比性限制。

适合长期研究和项目上下文复用，可与原文检索组合；不是托管产品或已实测优于 RAG 的架构。需要核验来源、版本和权限，防止错误持续积累。本库未启用自动编译或自动回写。
