# 知识库介绍摘要

服务大模型的知识库连接通用模型与具体业务，为任务供给有来源、版本、适用范围及权限边界的上下文。基础层关注知识可达，进阶层关注持续积累，企业层关注行动治理：分别可借助 RAG、LLM Wiki、图谱与本体等方式，按需组合，而非固定升级阶梯。

AI Coding 需要规则、设计理由、当前代码与接口事实、工具操作依据和验证方法。知识不能代替执行授权，回写结果应先验证与审查。知识库不自动保证正确或实时，图谱路径也不等于大模型内部推理可审计。本库目前是分层文档资产，未部署上述运行时系统。

本体建立共享语义与业务模型；运营型应用进一步连接业务状态、行动与治理，不应将其仅概括为术语和关系定义。具体执行能力取决于平台与工具实现。
