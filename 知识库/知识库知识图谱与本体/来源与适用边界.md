# 来源与适用边界

查阅日期：2026-10-12。

| 一手来源 | 支持内容 | 边界 |
|---|---|---|
| [W3C OWL 2 概述（2012）](https://www.w3.org/TR/owl2-overview/) | 本体词汇、类／属性／个体、形式语义及 RDF 图表示 | 不将 OWL 视为全部领域本体的唯一实现，不推定自动执行工具或检查必填字段 |
| [W3C RDF 1.1 概念（2014）](https://www.w3.org/TR/rdf11-concepts/) | 三元组与 RDF 图的基本表示 | RDF 图不是完整知识管理系统，也不是知识图谱唯一表示方式 |
| [W3C SHACL（2017）](https://www.w3.org/TR/shacl/) | 按条件校验 RDF 数据图 | 不等同于验证现实事实真实、执行业务权限或揭示模型推理 |
| [Palantir 本体概述](https://www.palantir.com/docs/foundry/ontology/overview/) | 产品中的语义要素与行动、函数、动态安全等运营要素 | 是具体运营型实现，不代表所有形式化本体都具备执行与权限机制；查阅于 2026-10-13 |

引用的是这些规范的指定版本，不作“最新所有版本”的声明。三者的工程分工、选型表、AI Coding 流程及对本仓库的建议是本库分析归纳；不同研究和产品对知识库、知识图谱的定义可能有差异。

正文下线接口案例为虚构教学示例。未建立图谱、运行 OWL 推理或 SHACL 校验，未执行实际接口变更。旧本体主题和路径保留，按需引用，不复制替换其内容。
