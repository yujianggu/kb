# 来源与适用边界

查阅日期：2026-10-13。

| 官方来源 | 本次支持内容 | 边界 |
|---|---|---|
| [W3C RDF 1.1 Concepts](https://www.w3.org/TR/rdf11-concepts/) | 三元组、RDF 图与 dataset 表示 | 不保证来源真实性，也不是所有图数据库的模型 |
| [Neo4j Graph database concepts](https://neo4j.com/docs/getting-started/appendix/graphdb-concepts/) | 节点、关系、类型及属性的属性图模型 | 不推定所有属性图库有完全相同的数据类型与行为 |
| [Apache Jena TDB2](https://jena.apache.org/documentation/tdb2/) | RDF 存储组件及访问／事务边界 | 不将本地存储当作无限并发或多进程写入服务 |
| [Jena 事务](https://jena.apache.org/documentation/txn/)、[TDB2 Fuseki 集成](https://jena.apache.org/documentation/tdb2/tdb2_fuseki.html) | 多读单写、服务化共享的方式 | Fuseki 不自动将 TDB2 变为分布式多写存储 |
| [NebulaGraph 3.8 数据模型](https://docs.nebula-graph.io/3.8.0/1.introduction/2.data-model/) | 有向属性图、空间及对象身份模型 | 具体版本的模型说明，不宣称无限规模或跨版本一致行为 |
| [ArangoDB 3.12 数据结构](https://docs.arango.ai/arangodb/3.12/concepts/data-structure/)、[图文档](https://docs.arango.ai/arangodb/3.12/graphs/) | 文档／图结合，节点与边集合及接口一致性边界 | 多模型能力不等于任意写入路径具备相同完整性保障 |
| [PostgreSQL WITH Queries](https://www.postgresql.org/docs/current/queries-with.html) | 递归查询能力及循环处理 | 能表达查询不等于本任务性能优于或差于图数据库 |
| [Amazon Neptune 查询文档](https://docs.aws.amazon.com/neptune/latest/userguide/access-graph-queries.html) | RDF 与属性图对应的查询语言 | 不据多模型支持推定跨模型查询或无损转换 |

上述页面实际读取；版本、部署、套餐及区域可能变化。路线适配、逻辑资产分工、断言模型及生命周期清单是本库分析建议，未进行产品部署、性能／成本测评或安全验收。断言模型为教学示例，不是可直接运行的数据库定义。
