# 检查路线

核对[目标](../business/refund-policy.md)、接口和验收条件，区分测试通过、审核接受、代码合并、部署完成及运行验证。

每个事件需要对应的版本、环境、时间及证据。缺少这些证据时，不得回答“14 天规则已在生产生效”。本样包没有执行任何部署。
