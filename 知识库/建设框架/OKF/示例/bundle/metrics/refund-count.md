# Definition

教学指标为左闭右开时间区间内的申请行数，假定演示表一行对应一次申请。它不表示退款金额、成功退款数量或唯一订单数量。

计算由独立[数量计算概念](../computations/refund-count.md)描述。实际表、去重与业务口径需验证，本样包没有任何真实计算结果。
