# Open Knowledge Format（OKF）摘要

OKF 是 Google Cloud 发布、面向人与 Agent 的厂商中立知识交换规范。本文按 2026-10-15 核对的 v0.2 解读：以目录分发知识，以 Markdown＋YAML frontmatter 承载 Concept，唯一始终必填的 frontmatter 键是 `type`。类型与目录可扩展，索引和日志可选。

v0.2 约定 `sources`、`generated`、`verified`、`status`、`stale_after` 等来源、验证和时效字段，并定义 Attested Computation，用于描述受认可计算及单次执行核验的接口。它不是检索引擎、本体推理器或执行平台，验证标签不等于身份认证或权限。

适合知识包交换、LLM Wiki 产物组织，以及业务问答和 AI Coding 的按需上下文供给。本库提供中文详解、完整英文规范快照与虚构教学样包，未安装参考 Agent 或运行计算核验。现有仓库仍使用自己的 topic.json 与索引约定，不自动符合 OKF。
