# PPAP 教学案例：动力电池冷却板生产件批准

> **案例性质：** 接续 [APQP 动力电池冷却板案例](../APQP/案例-动力电池冷却板.md)。本项目、供应商、数据、检验条件、客户要求和批准结果均为虚构，旨在说明 PPAP 的证据与决策链；不得直接用于真实零部件验收。

## 1. 提交约定

某新能源汽车公司为新车型选定冷却板供应商。研发发布冷却板图纸 **B 版**，客户质量团队要求供应商按本项目约定的 **Level 3** 提交生产件批准资料。该级别仅是本教学项目假设；真实提交级别由客户指定。[PPAP 提交级别说明示例](https://www.sensata.com/sites/default/files/a/QMS_1004255_SENSATA_GSQM.pdf)

| 项目字段 | 教学假设 |
|---|---|
| 零部件及版本 | 动力电池冷却板，图纸 B 版 |
| 提交原因 | 新零部件首次生产件批准 |
| 制造范围 | 供应商甲工厂、1 条拟量产焊接与检漏生产线 |
| 客户指定级别 | Level 3：PSW、代表性生产件样品和完整支持资料 |
| 示例关键要求 | 检漏：200 kPa、稳压后 60 秒内压力降不超过 1.0 kPa；某焊缝可测量特性的项目目标 Cpk ≥ 1.33 |
| 示例需求 | 量产爬坡后每月 30,000 件；按客户要求验证产能 |

以上检漏条件、能力目标和需求量均为虚构。真实项目的接受准则、样本量、统计方法及客户批准权限，应在提交前正式确定。

## 2. 首次试生产：发现问题，暂停提交

供应商用拟量产的材料、工装、设备、操作人员和节拍生产首批 **500 件**，其中 **6 件**检漏失败，观察失效率为 **1.2%**。同时，焊缝某可测量特性的示例 Cpk 为 **1.09**，低于本项目假设目标 **1.33**。该批次不能作为满足要求的批准证据。

供应商隔离该批次并保留零部件序列号、焊接机台、工艺参数、检漏曲线和班次记录。PTC 联合供应商排查发现：保护气调压器在连续运行时流量波动，夹具定位件也有磨损。供应商更换调压器、增设低流量停机互锁、修复定位件，并更新 PFMEA、控制计划、作业指导和设备点检要求。

此时 PST 更新车型节点风险，PSM 评估试生产失败对后续供货的影响。**进度紧张不改变质量结论**：若客户需要试装样件或临时发运，必须走其明确的偏差或临时批准流程，而不能把未批准批次当作常规量产件。[客户临时批准与发运限制示例](https://www.sensata.com/sites/default/files/a/QMS_1004255_SENSATA_GSQM.pdf)

## 3. 整改后重新取得代表性证据

供应商在修复后的**拟量产状态**再次生产 **500 件**，观察到 **0 件**检漏失败；该可测量焊缝特性的示例 Cpk 为 **1.46**。这些数字只说明本次观察结果，不能单独推出真实缺陷率为零，也不能代替测量系统、材料、尺寸、耐久、产能等其他验证。

内部 PPAP 评审还应核对：

1. **设计与版本：** B 版图纸、零部件号、规格、材料及适用工程批准与送检样品一致。
2. **过程与风险：** 过程流程图包含保护气监控、焊接、检漏和异常隔离；PFMEA 与控制计划已把本次失效及互锁措施写入。
3. **测量：** 检漏设备经过适合其判定方式的 MSA/挑战样验证；温度补偿和边界样件误判风险已经评估。
4. **产品验证：** 尺寸、材料、耐压、密封和约定寿命试验完成，并可追到本次生产批次。
5. **过程验证：** 焊缝特性的统计结果有稳定性与数据有效性依据；产能、包装、追溯及现场执行经验证。
6. **开放问题：** 首批失败件和整改结果有闭环记录；若仍有遗留问题，按客户正式流程处置。

AIAG 对 PPAP 的核心要求是用实际生产运行及生产速率下的证据，证明制造过程能持续满足设计和规范要求。[AIAG PPAP 手册介绍](https://www.aiag.org/training-and-resources/manuals/details/PPAP-4)

## 4. 示例提交包如何组织

| 资料包部分 | 本案例应能展示什么 |
|---|---|
| 设计依据 | B 版图纸、材料及检漏规范；适用工程变更/批准记录 |
| 风险与过程 | 过程流程图、整改后的 PFMEA、控制计划、作业/检验要求 |
| 测量与产品结果 | 检漏系统验证、尺寸结果、材料与性能试验、实验室资格文件 |
| 量产能力 | 再次试生产的批次、设备/工装/人员/节拍记录、初始过程研究和适用产能验证 |
| 样品与追溯 | 来自再次试生产的送样件、编号、标准样品及批次/设备/测试数据关联 |
| 客户特定材料 | 客户要求的材料申报、专门验证或表单；无外观批准需求时记录不适用依据 |
| PSW | 供应商、零部件号、图纸版本、制造地点、提交原因、级别及声明，与上述资料指向同一生产状态 |

提交前由供应商完成内部一致性评审，PTC 对质量技术证据提出评审意见，研发确认设计与工程批准，PSM 评估供应安排，PST 协调项目节点。**客户正式批准是发运条件的依据；内部评审不能替代客户决定。**福特和 Sensata 的公开客户文件均说明客户可规定特定提交与批准方式。[福特 PPAP 特殊要求](https://www.iatfglobaloversight.org/wp/wp-content/uploads/2026/06/Ford-Specifics-for-PPAP_June-2026-SCCAF-_-Final.pdf)；[Sensata 供应商质量手册](https://www.sensata.com/sites/default/files/a/QMS_1004255_SENSATA_GSQM.pdf)

## 5. 三种可能的客户结果

| 客户结论 | 本案例的下一步 |
|---|---|
| **批准** | 将批准的图纸、工艺、制造地点、控制计划及其他条件作为量产基线；按约定开始常规供货。 |
| **临时批准** | 只在客户明确的期限、数量和附加控制条件内供货；追踪未关闭事项并按期重提。 |
| **拒绝** | 不按正常量产批准状态发运；查清拒绝原因，整改后重新取得代表性样品和证据。 |

本教学案例假设：资料一致、客户要求均满足后，客户给出**批准**；这只是说明流程终点，不能据此推断任何真实供应商或零部件已获批准。

## 6. 获批后发生变更

三个月后，供应商拟更换铝板原材料供应商。即使零部件号仍不变，也应先评估材料差异对成形、焊接、密封性和过程能力的影响，确认客户通知要求、需要重新验证的项目和是否重提 PPAP。未经所需批准，不应直接把新材料件混入按旧批准状态供货的批次。福特公开的 PPAP 客户特殊要求将多种设计与制造变化列为提交情形；实际项目应按自己的客户规则执行。[福特 PPAP 客户特殊要求（2026）](https://www.iatfglobaloversight.org/wp/wp-content/uploads/2026/06/Ford-Specifics-for-PPAP_June-2026-SCCAF-_-Final.pdf)

## 7. 本案例的核心教训

PPAP 要形成一条可审查的链：**批准的要求 → 拟量产过程 → 代表性样品与数据 → 不合格整改及重新验证 → 一致的提交包 → 客户正式决定 → 变更后维持受控**。首次试生产不合格时，补齐文件或只挑选合格样品都不能替代问题闭环。
