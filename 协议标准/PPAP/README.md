# PPAP：生产件批准程序

**PPAP** 是 *Production Part Approval Process* 的缩写，中文通常称为**生产件批准程序**。其核心是向客户证明：零部件符合已批准的设计与规范，并且拟量产过程能在实际生产条件和节拍下持续制造符合要求的产品。AIAG 当前列示的手册为 **PPAP 第四版（第二次印刷）**。[AIAG PPAP 手册介绍](https://www.aiag.org/training-and-resources/manuals/details/PPAP-4)

## 阅读路径

1. [PPAP 方法与交付物](PPAP-方法与交付物.md)：适用情形、实施流程、常见的 18 类证据、提交级别、批准状态、变更后的再提交和角色协作。

3. [来源与适用边界](来源与适用边界.md)：AIAG 和汽车客户公开资料，以及本文的归纳和教学假设。

## 与 APQP 的关系

[APQP](../APQP/README.md) 负责在开发过程中规划、执行和改进质量工作；PPAP 汇集量产条件下的产品与过程证据，按客户要求提交并取得生产件批准。PPAP 获批后，持续生产和后续变更仍须受控。[AIAG 质量核心工具](https://www.aiag.org/expertise-areas/quality/quality-core-tools)

本目录是研究与教学材料，不替代 AIAG 正式手册、客户特殊要求、企业程序或真实项目的批准记录。案例数据均为虚构。
