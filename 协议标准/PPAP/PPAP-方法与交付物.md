# PPAP 方法与交付物

> **适用范围：** 汽车零部件首次生产件批准，以及客户要求通知或重新提交的设计、工艺、设备、生产场地、供应商等变更。本文是基于公开一手资料的工作说明，不是 PPAP 手册的替代文本。具体要求以 AIAG PPAP 第四版、适用客户特殊要求和项目协议为准。资料核对日期：2026-10-10。

## 1. PPAP 到底批准什么

PPAP（Production Part Approval Process，生产件批准程序）要证明两件事：**供应商理解并满足工程设计和规范要求；拟量产制造过程在实际生产条件及节拍下有能力持续制造合格件。** AIAG 当前列示的《PPAP》为第四版、第二次印刷。[AIAG PPAP 手册介绍](https://www.aiag.org/training-and-resources/manuals/details/PPAP-4)

它连接开发与正式供货，但不是一次样件送检，也不是单纯把文件凑齐。客户可能要求提交不同层级的证据，并对生产件给出批准、临时批准或拒绝等状态；允许发运的范围应以客户正式决定为准。[Sensata 供应商质量手册中的 PPAP 规则](https://www.sensata.com/sites/default/files/a/QMS_1004255_SENSATA_GSQM.pdf)

在采购流程中，**供应商定点**决定由谁承担某项目的零部件开发和后续供货；**PPAP 批准**判断该零部件及其拟量产过程是否取得客户所要求的生产件质量认可。定点、商务合同、采购订单与 PPAP 分别留有各自的决策和记录，不能互相代替。APQP 的前期风险评估可能在定点前开始，项目质量策划则通常继续贯穿定点后的开发过程。

| 概念 | 主要回答的问题 | 典型输出 |
|---|---|---|
| [APQP](../APQP/README.md) | 开发过程中怎样提前策划并降低产品与过程风险？ | 需求、FMEA、控制计划、验证、风险闭环和量产准备证据 |
| PPAP | 量产条件下的产品和过程是否达到客户规定的批准条件？ | 生产件样品、验证与过程数据、适用支持资料、PSW 及客户批准结果 |
| 量产控制 | 获批后怎样持续按受控状态生产，并管理变更？ | 量产监控、问题闭环、变更通知和必要的再验证/再提交 |

AIAG 将 APQP、控制计划、PPAP、FMEA、MSA、SPC 列为协同使用的汽车质量核心工具。[AIAG 质量核心工具](https://www.aiag.org/expertise-areas/quality/quality-core-tools)

## 2. 什么时候启动或重新启动

典型触发包括：新零部件首次量产；零部件设计或规范变化；制造过程、设备/工装、生产场地、原材料或供应商变化；客户要求的产能或批准条件变化。**并非每一项变化都自动要求同样范围的 PPAP**：先按客户的通知和批准规则评估，再确定重做的验证及提交内容。福特 2026 年面向 SCCAF 流程项目的 PPAP 客户特殊要求列举了新工装件、设计变更、制造过程或设备变化、已验证产能被提高等提交情形，说明客户规则会细化通用框架。[福特 PPAP 客户特殊要求（2026）](https://www.iatfglobaloversight.org/wp/wp-content/uploads/2026/06/Ford-Specifics-for-PPAP_June-2026-SCCAF-_-Final.pdf)

每次启动先确定一张“提交约定”：**客户、零部件号与图纸版本、供应商及制造地点、提交原因、提交级别、样品与资料要求、能力/试验准则、提交日期、批准人、可发运条件**。缺少其中关键项时，应先向客户授权代表确认。[IATF 官网客户特殊要求入口](https://www.iatfglobaloversight.org/oem-requirements/customer-specific-requirements/)

## 3. 一次 PPAP 的工作流程

1. **确定范围：** 对照最新图纸、技术规范和客户特殊要求，确认零部件、版本、制造场地、生产工艺、提交原因与级别；识别适用/不适用的资料项。
2. **完成量产准备：** 确认 APQP 遗留问题、过程流程图、PFMEA、控制计划、作业文件、工装、检具、追溯和产能要求已经落实。
3. **进行代表性生产：** 用拟量产的场地、设备、工装、材料、人员、检验方法和节拍生产代表性零部件；保留批次、时间、设备、过程与样品关联记录。AIAG 特别强调实际生产运行和生产速率。[AIAG PPAP 手册介绍](https://www.aiag.org/training-and-resources/manuals/details/PPAP-4)
4. **验证产品与过程：** 做尺寸、材料/性能试验、测量系统分析、初始过程研究及适用的产能或客户专项验证；不符合项应分析、整改并重新取得有代表性的证据。
5. **内部评审并提交：** 核对图纸/规范版本、样品、试验数据、FMEA、控制计划和 PSW（Part Submission Warrant，零件提交保证书）相互一致，按客户规定的级别和渠道提交。
6. **接收客户决定：** 记录批准状态、限制条件和有效范围；临时批准按客户明确的数量、期限或条件执行；拒绝则整改后重提。
7. **维持批准状态：** 获批后持续按受控过程生产；变更和问题按客户规则通知、再验证、必要时重新提交。[Sensata 供应商质量手册](https://www.sensata.com/sites/default/files/a/QMS_1004255_SENSATA_GSQM.pdf)

## 4. 常见的 18 类证据

下表按 AIAG PPAP 第四版的资料结构作简要说明；**“有 18 类”不表示每次都要向客户交齐 18 份文件**。具体适用性、提交还是留存、客户要求的格式及证明深度由手册、提交级别和客户特殊要求决定。公开的福特 PPAP 客户特殊要求沿用这些章节名称，并对部分内容追加客户要求。[福特 PPAP 客户特殊要求目录（2026）](https://www.iatfglobaloversight.org/wp/wp-content/uploads/2026/06/Ford-Specifics-for-PPAP_June-2026-SCCAF-_-Final.pdf)

| 序号 | 证据类别 | 审查要点 |
|---|---|---|
| 1 | 设计记录 | 当前获授权的图纸、3D/规范及零部件版本；零部件号与提交资料一致 |
| 2 | 已批准的工程变更文件 | 提交版本涉及的变更是否已正式批准和传达到供应商 |
| 3 | 客户工程批准 | 若客户要求，是否取得必要的技术认可或试验批准 |
| 4 | 设计 FMEA（适用时） | 有设计责任的一方是否识别设计失效与措施；无设计责任时按客户要求处理 |
| 5 | 过程流程图 | 从来料到包装的实际工序、返工和外协路径是否完整 |
| 6 | 过程 FMEA | 关键工序失效、预防/检测措施与实际控制是否一致 |
| 7 | 控制计划 | 特性、方法、频率、追溯及异常反应能否在产线执行 |
| 8 | 测量系统分析（MSA） | 关键检具和测试系统能否可靠区分合格与不合格 |
| 9 | 尺寸结果 | 规定尺寸的实测数据与图纸/规范版本是否一致 |
| 10 | 材料与性能试验结果 | 材料、功能和耐久验证是否覆盖适用要求 |
| 11 | 初始过程研究 | 关键特性的过程稳定性/能力及不满足要求时的处置 |
| 12 | 合格实验室文件 | 内部或外部实验室资质、能力与所执行试验的对应关系 |
| 13 | 外观批准报告（适用时） | 外观受控零部件是否完成客户要求的外观批准 |
| 14 | 生产件样品 | 样品是否来自本次代表性生产，能追到批次和制造条件 |
| 15 | 标准样品 | 留存的对照样品是否有标识、保存和版本管理 |
| 16 | 检查辅具 | 专用检具、夹具、模板等是否受控并能正常使用 |
| 17 | 客户特殊要求 | 例如客户指定的材料申报、产能验证、专项批准等是否完成 |
| 18 | PSW | 对提交范围与结果作正式声明，并记录客户批准状态 |

**关键检查不是文件数量，而是贯通性：** 同一零部件号、图纸版本、制造地点、材料/过程版本和样品批次，要能在 PSW、检验报告、FMEA、控制计划与生产记录中对上。若设计无责任、没有外观要求或无工程变更，应按适用手册和客户规则说明“不适用”的依据，不要伪造一份空白证明。

## 5. 提交级别与批准状态

PPAP 通常使用 **Level 1–5** 表示向客户提交/供客户审核的证据范围。下表仅是便于沟通的概括；客户可指定提交级别、增补项目和审核方式。Sensata 的供应商手册给出了这五级的公开定义，并明确由其 SQE 指定级别。[Sensata 供应商质量手册](https://www.sensata.com/sites/default/files/a/QMS_1004255_SENSATA_GSQM.pdf)

| 级别 | 常见提交方式概括 |
|---|---|
| Level 1 | 提交 PSW；适用的支持资料仍按要求留存 |
| Level 2 | 提交 PSW、样品和有限的支持资料 |
| Level 3 | 提交 PSW、样品和完整支持资料 |
| Level 4 | 提交 PSW 及客户明确指定的其他资料 |
| Level 5 | 提交 PSW、样品；完整支持资料在供应商制造现场供客户审查 |

**提交级别决定证据如何呈现，不代表零部件质量可以降低到某一级。** 不应自行认定“默认 Level 3”；应以客户通知为准。某些客户确实把 Level 3 设为其默认要求，这属于客户规定而非所有企业通用规定。[Sensata 供应商质量手册](https://www.sensata.com/sites/default/files/a/QMS_1004255_SENSATA_GSQM.pdf)

常见批准结果可理解为：

- **批准（Approved）：** 客户认可该提交范围的生产件和过程证据，后续按批准条件供货。
- **临时批准（Interim Approval）：** 客户允许在明确的期限、数量或条件内供货，供应商仍须完成遗留问题并取得后续批准。
- **拒绝（Rejected）：** 当前提交不足以支持批准，应整改并按客户要求重新提交。

上述术语和发运权限必须看客户正式记录。福特公开的 PPAP 特殊要求设有批准、临时批准和拒绝等状态章节；Sensata 则明确临时批准的数量/时间限制和未批准时的发运要求。[福特 PPAP 客户特殊要求](https://www.iatfglobaloversight.org/wp/wp-content/uploads/2026/06/Ford-Specifics-for-PPAP_June-2026-SCCAF-_-Final.pdf)；[Sensata 供应商质量手册](https://www.sensata.com/sites/default/files/a/QMS_1004255_SENSATA_GSQM.pdf)

## 6. 在新能源汽车零部件项目中的协作

以下是结合 [PST、PSM、PTC 关系说明](../../企业经营研究/新能源-lx/供应链/PSM-PST-PTC-角色关系.md) 的**建议分工**，不是企业正式授权矩阵：

| 角色 | PPAP 中关注的事项 |
|---|---|
| 供应商 | 组织代表性生产、检测和资料编制；保证数据、样品、工艺和提交版本一致；整改并保存记录 |
| 研发/产品 | 确认设计记录、工程变更、技术验收和必要的工程批准 |
| PTC | 评审供应商质量与工业化证据、FMEA/控制计划/MSA/验证结果，推动问题关闭，并按授权进行质量批准或提出结论 |
| PSM | 评估批准状态对采购、库存、交付和保供的影响；避免将未经允许的零部件纳入常规供货 |
| PST | 跟踪车型/项目节点与跨团队风险，协调质量、供应和进度冲突的项目级决策 |

最终客户批准、让步/偏差、临时发运等权限应以企业与客户的正式流程为准。

## 7. 评审时重点查什么

- **版本：** PSW、图纸、试验、样品和过程控制是否指向同一批准版本？
- **代表性：** 样品是否由拟量产条件下的实际过程产生？产能数据是否覆盖约定节拍？
- **风险：** APQP 遗留的高风险问题是否关闭，或取得有权限的书面处置？
- **一致性：** 过程流程、PFMEA、控制计划、作业文件和现场是否相互吻合？
- **测量：** 关键特性的测试系统是否经过适当 MSA，试验条件和接受准则是否明确？
- **能力：** 初始过程研究是否使用适当统计方法，未满足目标时是否有隔离/整改及再验证？
- **客户要求：** 提交级别、格式、样本量、材料申报及批准渠道是否符合该客户最新规定？
- **发运：** 未批准或临时批准状态下，允许发运的范围、数量和期限是否有明确记录？
- **变更：** 获批后零部件、材料、设备、工艺、场地或供应商改变时，是否触发通知、评估和必要的再提交？

## 8. 常见误区

- **把样件合格当作量产批准。** 样件可能来自试制设备，不能证明拟量产过程能力。
- **把 PSW 签好当作 PPAP 完成。** PSW 应与底层样品和数据一致，且客户需给出正式批准状态。
- **以提交级别低为由不保留证据。** 级别主要决定提交方式；适用的支持资料仍须按客户规则准备和保存。
- **试生产发现不合格后沿用原批次数据。** 整改后的代表性生产和受影响验证应重新完成。
- **把批准视为永久有效。** 后续变更或过程失控需要按客户要求通知、再验证或再提交。
