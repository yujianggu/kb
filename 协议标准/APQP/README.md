# APQP：产品质量先期策划

**APQP** 是 *Advanced Product Quality Planning* 的缩写，中文为**产品质量先期策划**。它通过跨职能规划，把客户要求转成可验证的产品设计、制造过程和量产控制要求，尽量在量产前识别并降低质量风险。AIAG 将其列为汽车行业质量核心工具之一。[AIAG 核心工具介绍](https://www.aiag.org/expertise-areas/quality/quality-core-tools)

## 阅读路径

1. [APQP 方法与落地](APQP-方法与落地.md)：适用场景、五个工作阶段、交付物、第三版重点、核心工具关系、评审与角色分工。
2. [案例：动力电池冷却板](案例-动力电池冷却板.md)：以虚构项目展示从质量风险识别到过程控制、试生产问题整改和量产放行。
3. [来源与适用边界](来源与适用边界.md)：AIAG 一手资料、版本信息和本文未覆盖的要求。

## 快速判断

APQP 不是一张表，也不是量产前一次性补齐的文件包。工作从需求和供应商风险识别开始，贯穿设计、过程开发、验证、试生产和量产后的反馈；设计、过程、测量、产能和供应链问题需要在各阶段持续联动。[AIAG APQP 第三版介绍](https://www.aiag.org/training-and-resources/manuals/details/APQP-3)

本目录是**研究与教学材料**，不替代 AIAG 正式手册、客户特殊要求、企业内部流程或项目批准记录。案例中的指标和数据均为虚构示例。
