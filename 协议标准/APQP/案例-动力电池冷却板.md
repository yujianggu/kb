# APQP 教学案例：动力电池冷却板

> **案例性质：** 以下为虚构的新能源汽车零部件项目，用来展示 APQP 的工作链条。项目、企业、数据、试验条件和放行门槛均为教学假设，不能作为行业标准或实际项目验收依据。实际要求以图纸、客户特殊要求、适用法规和批准的试验规范为准。

## 1. 项目背景与质量目标

某新能源汽车公司为新车型开发动力电池冷却板，由一级供应商进行铝板成形、焊接和总成检漏。冷却板若泄漏，可能导致冷却性能下降、返工，严重时影响电池包可靠性；因此需要在设计、焊接过程、检测和追溯四个层面建立控制。

| 教学假设 | 示例值/说明 |
|---|---|
| 项目需求 | 量产爬坡后每月供应 30,000 件；每件冷却板有唯一追溯码 |
| 关键产品特性 | 在约定试验条件下不泄漏；外形与接口尺寸符合批准图纸 |
| 示例检漏条件 | 200 kPa、稳压后测试 60 秒、压力降不超过 1.0 kPa；温度补偿和设备误差需另行验证 |
| 示例过程目标 | 某可测量焊缝特性达到项目约定的过程能力门槛，例如 Cpk ≥ 1.33 |
| 量产准备原则 | 用拟量产工装、设备、材料、人员、节拍和检测方案完成验证；未关闭的高风险问题不得直接转为“已准备就绪” |

上表所有数值均为**便于演示而设**。特别是检漏压力、允许压降、样本量和 Cpk 门槛，应由真实产品设计、风险等级和客户要求决定。

## 2. 从需求到控制的证据链

| 需求或风险 | APQP 阶段中的处理 | 形成的证据 |
|---|---|---|
| 冷却板不得泄漏 | 研发定义检漏条件和接受准则；设计团队分析接口、焊缝和材料的失效方式 | 图纸/试验规范、设计评审、DFMEA、设计验证报告 |
| 焊缝气孔可能导致泄漏 | 供应商建立过程流程和 PFMEA；识别保护气、激光功率、夹具定位等因素 | 过程流程图、PFMEA、工艺窗口确认记录 |
| 失效不得流出 | 预防措施、100% 成品检漏、异常自动隔离、设备挑战样验证 | 控制计划、设备验证、作业指导、异常反应记录 |
| 数据要能追到受影响批次 | 记录材料批次、设备/工装、工艺程序、生产时间和每件检漏结果 | 追溯规则、数据抽查、模拟追溯报告 |
| 量产节拍下仍能稳定生产 | 在拟量产条件下试生产，验证测量系统、过程能力、产能和包装运输 | MSA、试生产记录、能力/稳定性分析、产能与包装验证、按客户要求提交的 PPAP |

这条链的核心是：**需求 → 失效分析 → 预防/检测 → 现场执行 → 量产条件验证 → 反馈改进**。仅提供一份检漏报告，无法证明焊接过程和追溯体系已经受控。[AIAG 质量核心工具](https://www.aiag.org/expertise-areas/quality/quality-core-tools)

## 3. 五个阶段如何推进

### 阶段 1：计划与项目定义

PST 牵引车型节点和跨部门计划；研发明确冷却板接口、寿命和检漏要求；PSM 确认采购、月需求与物流条件；PTC 与供应商评估新工艺、质量体系、试验能力及下级材料供应风险。

**本阶段交付：** 客户需求及版本清单、项目时间表、关键特性初稿、供应商能力初评、产能和质量风险台账。若供应商尚无批量焊接能力，风险台账应给出设备到位、试验验证和替代方案的责任人与完成时间。

### 阶段 2：产品设计与开发

研发与供应商确定流道、材料和焊缝设计。DFMEA 识别可能的泄漏路径及影响，提出设计优化和验证项目，例如焊缝可达性、耐压与冷热循环验证。PTC 审视关键质量特性和验证覆盖情况，确保设计风险能传递给后续过程控制。

**本阶段交付：** 受控图纸、材料与试验规范、DFMEA、样件验证报告、特殊特性清单、设计变更记录。

### 阶段 3：过程设计与开发

供应商绘制“材料接收 → 成形 → 清洗 → 夹紧 → 激光焊接 → 检漏 → 包装”的过程流程。PFMEA 将“保护气流量不足导致焊缝气孔”列为需采取措施的风险：安装流量监测与设备互锁，规定焊接程序/夹具的校验；成品检漏机对每件记录结果，失败件自动隔离。

| 控制对象 | 示例控制措施 | 异常反应 |
|---|---|---|
| 保护气流量 | 设定工艺窗口、实时监控与低流量停机互锁 | 停机；隔离自上一次合格监控点后的产品；评估复检范围 |
| 夹具定位 | 定期点检定位件与防错确认 | 停止该工位，维修并验证后重启 |
| 成品密封性 | 每件自动检漏；按规定频率用已知状态样件挑战设备 | 不合格件隔离；若设备挑战失败，追溯并复核受影响区间 |
| 追溯记录 | 每件关联材料批次、生产设备/程序和检漏结果 | 数据缺失的零部件隔离，不按合格品交付 |

**本阶段交付：** 过程流程图、PFMEA、控制计划、工艺/检验作业指导、测量系统验证计划、设备与工装验收计划、追溯方案。关键核对是流程图、PFMEA 和控制计划对同一工序及特性的描述一致。[AIAG 控制计划介绍](https://www.aiag.org/expertise-areas/quality/quality-core-tools)

### 阶段 4：产品与过程验证

供应商先验证检漏设备：使用已知合格/不合格的标准样件与边界样件，考察重复判定、误判以及温度变化对压力降的影响。通过后，在拟量产条件下开展试生产，验证产品、过程、节拍、产能、包装和追溯。

**试生产中出现的问题（教学数据）：** 首批 500 件有 6 件检漏失败，观察失效率为 6 ÷ 500 = 1.2%。PTC 和供应商暂停量产就绪结论。追查发现保护气调压器在连续高节拍下流量波动，同时夹具定位件磨损。供应商更换调压器、增加低流量互锁、修复夹具，并更新 PFMEA、控制计划、维修和设备挑战要求。

**整改后的验证（教学数据）：** 在相同拟量产节拍下再生产 500 件，观察到 0 件检漏失败；焊缝某可测量特性的 Cpk 从示例值 1.09 提升至 1.46。PTC 仍需确认测量系统、过程稳定性、样本覆盖、设计验证和客户要求的 PPAP 结果。**“500 件零缺陷”本身不等于真实缺陷率为零，也不足以单独批准量产。**

**本阶段交付：** 检漏设备验证/MSA、试生产与失效分析、整改及再验证、过程能力和产能数据、包装物流验证、控制计划定版，以及按客户要求提交并获批的 PPAP 资料。AIAG 将 PPAP、MSA、SPC 和控制计划列为与 APQP 配合的核心工具。[AIAG 质量核心工具](https://www.aiag.org/expertise-areas/quality/quality-core-tools)

### 阶段 5：量产反馈与持续改进

进入量产初期后，供应商按约定执行更严格的安全启动监控；PTC 关注泄漏率、误判、焊接工艺漂移和整改措施有效性；PSM 关注合格产出、库存及交付风险；PST 关注车型项目节点。安全启动的退出依据应在项目中事先约定并保留审批记录。[AIAG 控制计划第一版更新说明](https://www.aiag.org/docs/default-source/quality-/apqp_cp-faqs.pdf)

若量产三个月后更换铝板供应商，应重新评估材料性质对成形、焊接、密封和产能的影响，更新风险分析与控制计划，确定重新验证范围，并按客户要求完成变更批准后切换。AIAG APQP 第三版专门增强了变更管理和下级供应商活动审视。[AIAG APQP 第三版白皮书](https://www.aiag.org/docs/default-source/quality-/aiag-plexus-apqp-white-paper-2023.pdf)

## 4. 这一案例的分工与决策

| 角色 | 本案例中的主要动作 |
|---|---|
| 研发 | 批准零部件要求和设计验证；处理设计变更与接口问题 |
| 供应商 | 执行 APQP、建立工艺与控制、提供验证和 PPAP 资料、管理下级材料供应商 |
| PTC | 审视供应商质量与工业化能力、质量风险、PFMEA/控制计划/验证证据；推动缺陷整改与质量就绪判断 |
| PSM | 管理需求、采购、产能与交付，评估停线/整改对供应的影响并制定保供措施 |
| PST | 统筹车型节点，组织跨部门决策；当质量整改与量产时间冲突时推动项目级风险评审 |

**阶段决策示例：** 首批试生产 500 件出现 6 件检漏失败时，项目不得仅因进度压力宣布“质量已就绪”。应记录问题、隔离产品、明确根因和整改责任，再以验证结果、开放风险与批准权限决定下一节点。PST 协调进度和资源，PTC 给出质量技术判断，PSM 提供供货影响与保供方案；最终批准仍按企业和客户流程执行。

## 5. 案例可复用的最小记录

真实项目可至少建立一条贯通的记录链：**需求编号 → 图纸/规范版本 → 风险项（DFMEA/PFMEA）→ 控制计划行 → 检测/过程数据 → 问题与变更记录 → 试生产/PPAP 批准 → 量产监控**。这样在发生泄漏、供应商切换或客户投诉时，能快速识别受影响零部件、控制缺口和需要重新验证的范围。
