# 汽车制造中的工艺与工装

整理日期：2026-09-08

本文用于理解汽车试制和制造中的基本术语。具体分类及技术要求以企业规范为准。

## 1. 基本含义

**工艺是“按什么方法、顺序和参数制造”，工装是“制造时用来定位、夹紧、成形、装配或检测的工具装置”。**

工装通常是“工艺装备”的简称，其范围可包括模具、夹具、专用工具、检具等。

| 对比项 | 工艺 | 工装 |
|---|---|---|
| 回答的问题 | 怎么做？先做什么？做到什么要求？ | 用什么辅助装置来做？ |
| 主要内容 | 工序顺序、操作方法、加工参数、装配要求、检查方法 | 模具、夹具、定位装置、专用装配工具、检具等 |
| 常见形式 | 工艺流程图、作业指导书、参数规范、工艺程序 | 实物工具或装置，以及对应设计图纸 |
| 汽车实例 | 焊接顺序、涂胶路径、螺栓拧紧顺序和力矩 | 焊接夹具、冲压模具、车门安装定位工装、尺寸检具 |

## 2. 实例：安装车门

**工艺**规定安装方法和操作要求，例如：

1. 定位车门。
2. 预紧铰链螺栓。
3. 调整间隙面差。
4. 按规定顺序和力矩完成拧紧。
5. 检查开关门效果。

**工装**是执行这些操作时使用的辅助装置，例如托住车门并辅助定位的装置、限制安装位置的定位块、检查间隙的专用量具。

以上顺序用于解释概念，不是具体车型的装配作业指导书。

## 3. 实例：车身焊接

- **工艺**规定焊哪些位置、先焊哪里，以及焊接电流、时间等参数。
- **工装**将不同钣金件固定在正确位置，防止焊接时移动，保证零件之间的位置关系。

工艺与工装需要相互匹配：焊接顺序要考虑夹紧和定位条件，夹具设计也要保证焊接工具能够到达指定位置。

## 4. 试制中的工艺与工装调整

| 发现的问题 | 可能的调整方向 | 调整类别 |
|---|---|---|
| 焊接后车身变形 | 调整焊接顺序或参数 | 工艺调整 |
| 钣金件放到夹具上位置不准 | 调整定位销、定位面或夹紧机构 | 工装调整 |
| 装配工具伸不进去 | 改变装配顺序，或修改专用工具 | 工艺与工装共同调整 |

上表是可能的处理方向，不是根因判定。例如焊接变形也可能与零件、夹具或夹紧条件有关，需要分析后确定对策。

## 5. 工装与设备的区别

| 对比项 | 设备 | 工装 |
|---|---|---|
| 主要作用 | 提供加工、运动、动力或控制能力 | 配合设备或人员完成具体产品的定位、夹紧、成形、装配或检测 |
| 焊接场景 | 焊接机器人、焊机 | 固定车身或钣金件的焊接夹具 |
| 冲压场景 | 压力机 | 压力机上安装的冲压模具 |

企业对工具、工装、检具和设备的资产分类可能不同，应以内部管理口径为准。
