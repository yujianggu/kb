# TQM 全面质量管理本体模型文档集

这组文档围绕 TQM / LI‑TQM 业务流程与质量管理本体展开，并补充 APQC PCF 7.4 标准对照。建议先阅读总体模型，再按需要展开价值流、平台架构和治理落地内容。

   说明建模依据、TQM 四大 L3 领域、核心对象、跨域关系、质量事件、指标和基本 Palantir Ontology 映射。

2. [TQM 质量价值流](./TQM-质量价值流.md)  
   说明 IVDP 生命周期、PQA 正向策划、QTR 逆向改进、质量门、价值流对象和端到端指标。

3. [LI‑TQM 平台架构本体](./LI-TQM-平台架构本体.md)  
   说明平台分层、质量应用、PQCP、QWO、JIRA、AI 质量专家、系统集成和平台治理。

4. [AI 质量专家（Qivis）](./AI质量专家-Qivis.md)
   说明 AI 质量专家的能力、本体对象、Function、Action 和权限审批边界。

5. [PCF 7.4 质量管理全景汇总](./PCF-7.4-质量管理全景汇总.md)
   按 APQC PCF 7.4 完整梳理 13.3 企业质量管理的 40 个节点，汇总跨业务质量流程、公共支撑和 TQM/PQCP 映射。

6. [车辆试制与生产阶段详解](./车辆试制与生产阶段详解.md)
   按研发样车试制、生产线试制两类整理阶段、动作、产出和总览图；标注理想汽车使用 PPV1／PPV2／PPV3、无 PT1／PT2，以及 Pre-PPV 起进入工厂端生产线试制的口径。

   整理问题分类表、问题类型与生产阶段关联图、分类边界，以及 VSE／DRE 的定义、职责对照和协作示例。

   解释工艺、工装与设备的区别，包含车门安装、车身焊接及试制调整实例。

## 阅读关系

```text
TQM 总体本体模型
        ↓
TQM 质量价值流
        ↓
LI-TQM 平台架构本体
```

总体模型回答“质量管理有哪些对象和能力”；价值流回答“质量价值如何在生命周期中流动”；平台架构回答“这些对象和能力由哪些系统和应用承载”。
