# 本体知识库

本项目按知识的适用范围组织：基础理论与方法、技术标准与格式、产品平台、行业案例、公司业务。**clx 是特定公司的业务资料，不是通用汽车质量知识目录。**

## 项目导航

| 分类 | 入口 | 内容范围 |
|---|---|---|
| 基础理论与方法 | [基础概念和建模方法](基础理论与方法/README.md) | 本体入门、建模步骤、运营型本体 |
| 技术标准与格式 | [RDF、OWL 与 OKF](技术标准与格式/README.md) | 知识表示模型、语言及格式资料；不将不同成熟度的技术都视为正式标准 |
| 产品平台 | [产品实现与比较](产品平台/README.md) | Palantir Ontology 的实现、构件与业务案例 |
| 行业案例 | [新能源车质量安全示例](行业案例/README.md) | 教学与设计示例，不代表特定企业真实系统 |
| 公司业务 | [公司资料索引](公司业务/README.md) | clx 的业务口径、平台应用、规划和发布归档 |

## 建议阅读顺序

初次了解本体：基础入门 → 建模方法 → 运营型本体。需要形式化表达时阅读 RDF、OWL；研究产品实现时进入 Palantir。理解方法后，再分别阅读行业案例与公司实际资料。

## 内容维护边界

- 基础理论不夹带企业专有组织、系统状态或项目目标。
- 技术语言、数据格式与厂商产品分开整理，原资料来源和限制说明继续保留。
- 行业案例须说明示例性质；公司事实、菜单核对及内部规划保留在对应公司目录。
- 公司资料中使用行业知识时，由正文注明通用语义与公司口径的区别；不因标题相似就抽取为通用结论。
- 所有目录通过 README 关联。应用正文、项目资料、资源与发布快照的维护规则由公司子目录说明。

本次整理只调整资料归属、导航和适用范围说明；未将旧技术内容重新核验为最新事实，也未重新生成发布文件。
